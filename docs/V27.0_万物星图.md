# 万物博物馆 V27.0｜万物星图

**把收藏与想法连接成自己的知识宇宙。**

## 1. 目标与交互

V26 的奇遇任务链帮助用户从随机结果继续探索真实馆藏；V27 新增一个私人空间，把用户实际收藏的东西和自己的想法组织成个人知识网络。

入口：左侧「✧ 万物星图」；在可访问的藏品详情中点击「✧ 加入我的万物星图」。

- **星点**：真实馆藏节点，或独立的个人想法节点。想法节点可保存标题和个人注记，不要求它已被证实。
- **连线**：馆长选择关系类型并解释原因，包括主题相近、历史脉络、影响或启发、相互对照、材料或工艺、意外关联、个人联想。
- **系统线索**：仅比较星图内本人当前有权访问的真实展品，根据共同标签、相同细分类别或相同领域生成有限候选。线索不自动入图，馆长主动确认后才保存为个人连线。
- **图形界面**：星点分布在夜空图中，个人连线以金色实线显示；下方提供完整节点列表、节点档案、关联列表、删除、搜索与导入操作。
- **馆藏搜索**：从当前公开社区馆藏检索后，用户可把真实展品加入私人星图。不是凭空生成示例藏品。

## 2. 明确的隐私规则

星图没有公开分享入口，所有 API 都需要登录，并且每次查询只返回当前账号拥有的星图节点与个人连线。

- **私人想法**：只存于该账号的星图节点中，不公开展示。
- **私人藏品**：允许馆长本人添加到自己的星图；其他用户不能通过星图读到。
- **公开藏品**：新增节点时检查当前访问权限。展品之后设为私密或撤回公开时，其他馆长星图不再显示原始标题。
- **不保留标题快照**：`constellation_nodes` 的展品节点只保存原始展品 ID、用户个人注记和来源标签；不复制展品标题、简介或标签。读取时实时从原始藏品加载。
- **删除或撤回**：展品被删除时，外键将星图节点的 `exhibit_id` 置空；被设为私密或撤回公开时，前端收到一个不带原始标题的占位节点，馆长可删除它。占位节点不能继续用于新建关联，也不参与系统线索。
- **幻想世界及创作工坊**：读取其他用户的展品时额外检查所属玄幻世界、创作工坊和沙盒项目是否仍允许公开，防止绕过撤回机制。
- **导入来源**：只导入本人藏品、本人心动收藏、本人自行标记的奇遇参观，以及已有的 `memory_views` 主动记录。不会偷偷打开浏览历史；该表只会由既有的明确启用记录动作产生。

## 3. 数据模型

### `constellation_nodes`

| 字段 | 含义 |
|---|---|
| `user_id` | 星图所有者 |
| `kind` | `exhibit` 或 `idea` |
| `exhibit_id` | 可选的原始展品外键；展品删除时自动置空 |
| `title` | 仅用于个人想法；展品标题不复制进此列 |
| `note` | 用户自己的私人注记 |
| `origin` | 手动加入、我的藏品、心动收藏、自标记参观或自愿浏览历史 |
| `created_at` | 加入星图的时间 |

### `constellation_edges`

| 字段 | 含义 |
|---|---|
| `user_id` | 关联所有者 |
| `from_node_id`, `to_node_id` | 两个同属该用户的节点 |
| `kind` | 用户选择的关系类别 |
| `note` | 用户解释的关系理由 |
| `created_at` | 保存时间 |

数据库使用外键、级联删除、每用户唯一约束和上限。后端不允许把别人的星图节点用于自己的连线。

## 4. API

| 路由 | 用途 |
|---|---|
| `GET /api/constellation` | 获取自己的节点、连线和有限的可解释线索 |
| `POST /api/constellation/nodes` | 添加真实展品或个人想法 |
| `DELETE /api/constellation/nodes/{node_id}` | 删除自己的节点及其连线，不删除原始藏品 |
| `POST /api/constellation/edges` | 主动保存一条个人关联 |
| `DELETE /api/constellation/edges/{edge_id}` | 删除自己的个人关联 |
| `POST /api/constellation/import` | 主动导入已有收藏和已授权的个人记录 |

### 上限

- 每人最多 80 个星点。
- 每人最多 400 条个人连线。
- 系统最多返回 12 条未保存的线索。
- 每种来源每次最多扫描 80 条记录；重复来源去重，重复导入不创建重复展品节点。

## 5. 关联解释的边界

系统只使用确定性的元数据重合：共同标签、相同细分类别、相同领域。它不会从相似标签推断历史因果，不会将用户自己的观点表述为平台认证，也不会自动替用户建立关系。

金色实线代表“这位馆长主动保存了这条关联”，而非“这条关联已被证实”。未来如果加入更强的语义检索，也应将算法候选、用户判断和可验证证据分别呈现。

## 6. 测试覆盖

`tests/test_constellation_v27.py` 覆盖：

- 登录与多账号隔离；
- 私有展品访问权限与重复节点；
- 手动关联、反向重复和删除；
- 标签/类别线索只建议、不自动保存；
- 展品设为私密或删除后的标题遮蔽；
- 主动导入藏品、收藏、浏览历史与自标记参观；
- 输入验证、静态资源、版本与导航接入。

浏览器视觉端到端和 80 节点以上的交互性能仍应在发布前单独验收。当前版本限制节点数以确保界面可用，不宣称可无限扩展。
