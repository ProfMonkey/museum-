# V20.0：万物实验室

**任何有趣的东西都可以成为博物馆的起点。** 本版从「玄幻文明」重新扩展至整个万物博物馆，新增四个直接可用的模块，继续沿用 FastAPI、SQLite 和原生前端，不新增付费依赖。

## 🎁 每日万物奇遇

从最近最多 400 件公开社区藏品和最多 120 个公开原创世界中，按服务器 UTC 日期、主题领域、类型计算确定性精选。选择同日同主题会出现相同的候选结果。未找到真实来源时明确显示空状态，不造假内容或用户。世界与现实投稿始终分别标记；社区投稿的事实并未由本站独立核验。

## 📚 万物图鉴

馆长创建最多 12 册主题图鉴，每册最多 24 件来源，可搭配现实社区投稿与原创玄幻世界，采用 6 种风格。默认私人。公开必须明确授权，且所有条目均已公开。一旦源条目私密或删除，公开读者也无法从旧图鉴读取。只保留对原藏品的引用，不转移所有权。

## ⏳ 私人时光胶囊

用户可保存最多 30 封文字信件，设置从下一日起至未来十年内的开启日期。服务器会遮蔽未到期的正文，即使是本人也无法从读取 API 提前获取。当前是个人的本地自托管档案，数据库管理员仍能直接访问数据库，因此并非端到端加密；重要信件另行备份。

## 🏅 奇遇护照

用户主动打开当日万物盲盒后可以领取一枚印章。每账号每日 UTC 仅能领取一枚。印章记录的是确实存在、已经公开的来源；若来源撤回或删除，印章保留但不泄露其私密内容。没有自动签到或虚构增长数据。

## 页面入口

左侧主导航「✶ 万物实验室」，含四个页签；支持手机宽度自适应。详细实现：

- 后端：everything_lab.py
- 前端：static/everything-lab.js 与 static/everything-lab.css
- 测试：tests/test_everything_lab_v20.py

## 核验

执行 `python -m pytest -q tests` 与 `node --check static/everything-lab.js`。浏览器真实操作、手机布局和公网高并发仍需独立验收。真实馆藏外链并不等于可以任意复制第三方受版权保护的原图。

## 下一步

V21 可将真实馆藏、原创世界与个人记忆串成经来源验证的互动探索地图；不过实物博物馆和虚构宇宙应保持显著区分，且不能用生成故事替代来源可追踪的事实。
