# 万物博物馆 V34.0｜万物文明演化实验室

> 从 V33 的两件真实公开藏品诞生一座架空世界，再由该世界创造者从其中一件物品开始，亲手写出一段**可复现的虚构文明史**。本模块不是对真实国家、文明发展或政策效果的科学预测。

## 🌍 玩家体验

**每个 V33 公开世界最多 6 个文明，每个文明最多 8 轮决策。**

馆长在自己已公开且两件源展品仍合法公开的 V33 世界中，任选其中一件作为「文明种子」。创建时填写文明名称和宣言，新文明默认为私密。

每轮，馆长选一项公开的游戏政策，并**亲自写下该时代的篇章和故事**：

- 研究未知：知识增长，牺牲少量物资与生态。
- 拓荒生产：补给增加，但有生态成本。
- 文明交流：提高凝聚力与文化。
- 生态修复：增加生态值，消耗补给。
- 艺术与传承：强化文化与凝聚。
- 封闭防御：增加凝聚，但削弱文化及知识。

五个显式游戏指标为「知识、物资、生态、凝聚、文化」，均为 0–100，初始均为 50。所有政策数值公开，V33 六种世界法则对部分决策有固定的 ±3 游戏影响。每个回合都有完整的计算前值、实际差值和后值，没有隐藏的黑箱预测。

### ☄️ 异世界物件冲击

例如，一个以「青铜古钟」为文明种子的架空世界，在第三轮突然得到一件「宇宙望远镜」。

馆长必须从博物馆中挑选**目前确实公开、且不属于这个母世界原始两件物品**的第三件藏品。这个可选游戏事件具有公开固定数值效果：

- 知识 +5
- 文化 +4
- 凝聚 −3

馆长接着亲自解释它在虚构故事里怎样改变文明。这里的数值只是事先约定的**游戏平衡参数**；不能推断真实原始社会获得望远镜后的实际变化。

第三件外来来源也将加入公开权限的实时验证；任一引用的原展品被删除、撤回或因父项目隐私变更失效，整座公开文明立即隐藏。

### 🔬 反事实历史显微镜

游客打开一段已经公开的文明史，可在 1 至 8 轮中选择一个**真正存在的历史抉择**，把那一轮政策替换为另一项。

引擎从之前已记录的数值开始重新计算：仅替换那一轮策略，后面的**策略顺序和已经加入的异世界物件冲击保持原样**。然后并列展示馆长原版的最终五维数值、假设路线的最终五维数值及差异。

- 反事实只读：不会覆盖原始决策、故事或状态。
- 不自动改写馆长的原创文字，不谎称模型真正预测了另一条世界历史。
- 文明在公共页面中只有合法公开来源、馆长自己写下的故事才会呈现。

## 🔐 权限与撤回

1. 只有该 V33 世界原作者才能创建其文明，也只有文明自己的原作者能追加/撤回回合、修改宣言、发布、下架和删除。
2. 新文明为私密草稿。至少亲自撰写两轮后才能公开。修改宣言、增加或撤销回合，立即转回私密待重新批准。
3. 只接受当前公开 V33 碰撞世界，且两件原始来源同时公开；所选种子必须是这两者之一。
4. 创建文明时记录 V33 母世界修订号。母世界修改或重新发布会增加修订号，**旧文明不会自动继承新版世界权限**；公开接口持续返回 404。
5. 所有公开请求严格实时校验 V33 两件源物品、文明种子、以及全部已经注入的外来第三方物件。撤回任何一个来源，即撤回整个历史；不复制源展品的旧标题、封面快照和说明。
6. 个人列表中来源无效的文明仅显示不可用占位，不会泄露原始作品名称、世界标题或故事内容。拥有者仍能将无效的文明删除。
7. 新功能不打通 V27 私人星图和 V28 私人航线，不会因公开这个架空世界而公开其他私有内容。

## 🧮 技术实现

- **`civilization_engine.py`**：纯函数模拟器 `apply_turn`，规则版本 `MODEL_VERSION=1`，边界 0–100，回合真实 delta 依据截断结果计算。输入相同、输出必定相同。
- **`civilization_lab.py`**：独立 FastAPI 模块与 SQLite `civ_civilizations`、`civ_turns`；父世界及所有源权限即时校验、作者专属写入、只读反事实回放。
- **`static/civilizations.js` / `static/civilizations.css`**：手机与桌面响应式文明创造工作台、五维状态条、透明年轮和历史分岔显微镜。
- **`tests/test_civilization_v34.py`**：新增本地集成测试，覆盖 V33 所有权、六文明上限、数值确定性、外来物件冲击、源撤回、版本、个人草稿及反事实只读。
- `server.py` 版本更新至 **34.0**，新导航「🏛️ 万物文明演化实验室」，分享入口 `?civilization=<ID>`。

### 主要 API

| 路径 | 用途 |
|---|---|
| `GET /api/civilizations/policies` | 查看全部透明规则和模型版本 |
| `GET /api/civilizations/relics?q=` | 检索当前合法公开的外来藏品 |
| `GET /api/civilizations/worlds` | 本人已公开的可用 V33 母世界与剩余名额 |
| `GET /api/civilizations` | 当前所有来源仍有效的公开文明目录 |
| `GET /api/civilizations/mine` | 个人私密草稿和公开文明列表 |
| `POST /api/civilizations` | 从自己的 V33 世界创建私人文明 |
| `GET /api/civilizations/{id}` | 查看当前已公开文明或本人草稿 |
| `PUT /api/civilizations/{id}` | 作者更新宣言并撤销旧公开状态 |
| `POST /api/civilizations/{id}/turns` | 作者追加策略、原创篇章和可选外来物件 |
| `DELETE /api/civilizations/{id}/turns/latest` | 作者撤销最新一轮 |
| `POST /api/civilizations/{id}/publish` | 至少两轮后作者主动公开 |
| `POST /api/civilizations/{id}/unpublish` | 作者主动恢复私密草稿 |
| `DELETE /api/civilizations/{id}` | 作者删除个人文明 |
| `GET /api/civilizations/{id}/counterfactual?turn=&policy=` | 对现有年代进行一轮替换的只读反事实模拟 |

## 🔋 GitHub Actions 额度保护

用户已明确禁止继续使用 GitHub Actions。本版本保持 `.github/workflows/ci.yml` 中 **只保留手动 `workflow_dispatch`，关闭所有 push/PR 自动触发**，本次工作不调用 Actions、不重新开启、不查询 CI 运行记录。

可以在开发者本机运行：

```bash
python -m pytest -q tests/test_civilization_v34.py
python scripts/check_local.py --quick
python scripts/check_local.py
```

这些是**本地验证命令**，不消耗 GitHub Actions 额度。添加测试文件或进行 JavaScript 静态语法检查不等于全套 Python 和真实浏览器验收完成。系统还没有经过真实浏览器端到端、大规模负载或经济模拟科学有效性验证。
