# V12.0 · 世界时间长河 × 证据关联 × 私人世界星图

这一版本是万物博物馆既有 `exhibits`、`exhibit_links`、`halls`、`hall_items` 表的三个不同视图；**没有第三套上传、收藏或者账号系统**。新增独立后端 `cosmos_api.py`，前端 `static/cosmos.js` 和 `static/cosmos.css`。

## Ⅰ 世界时间长河

`GET /api/cosmos/eras?series=全部&domain=全部&scope=public`

- 按 V10 的 11 个宽泛时代分组，按年代从远到近排列，不将展品的“提交时间”当成“形成或制作时间”。
- 每个年代独立抽取最多 20 件最新公开展品；每段总数由 SQLite 全部符合条件的记录统计，避免新兴互联网展品遮蔽古老藏品。
- `scope=mine` 需要登录，只看当前账号自己的展品，包括私人收藏；不会因为个人筛选而把内容加入公共时间长河。
- 支持系列、领域的联动筛选；时代不能代表精确年代，`time_basis`、`time_note` 留存原文。
- 还没有真实展品的时代展示空状态和世界名馆入口，不虚构“47 亿年代表展品”。

## Ⅱ 证据关联：只回答“为什么被推荐”，不冒充事实推理

`GET /api/cosmos/relations/{exhibit_id}?limit=12`

算法从当前用户可以查看的展品中抽取最近 1000 个候选；匹配依据依次为：

| 依据 | 权重 | 解释 |
| --- | ---: | --- |
| 共同标签 | 每条 5，最多 15 | 原样展示确切重合的标签 |
| 同细分类别 | 7 | 分类相同（排除“其他”） |
| 同领域 | 3 | 共同属于已注明领域 |
| 同时间尺度 | 2 | 只有时间不是“时间不详/跨越多个时期”时适用 |
| 同来源网站域名 | 2 | 只是链接来自同一域，不代表事实同源或相互影响 |

**没有共同标签、细类或领域**时，即使时间相同/网址同域，也不生成推荐。推荐列表最多 24 件，显示分数及可读证据，但分数**不是可信度分、事实核实结果或历史因果证明**。人工关联从 V11 `exhibit_links` 读取并单独展示作者及说明，标注“用户陈述·未经独立核验”。无访问权限的私人展品不会出现在推荐、人工关系或搜索入口中。

## Ⅲ 我的世界星图

`GET /api/cosmos/me/map`（登录后）

- 返回当前账号最近最多 150 件自己的展品、各领域统计、个人展厅及展品归属、本人提交且两端均属于自己的人工关联。
- 客户端 SVG 将领域渲染为不同的星域，展品显示为可点击的星点；用户可按领域突出展示。
- 图谱与统计不会发布动态，也没有引入人格或商业兴趣画像。账户之间严格隔离。
- 兼容私密展厅和私人展品，控制最大渲染规模，减少普通笔记本上的卡顿。

## 权限/性能/测试

V12 接口采用现有 session 授权函数 `maybe_user` / `require_user` / `read_exhibit`，不存在新的跨域 API。无权内容在 SQL 和结果组装两个层次分别过滤。公开时间长河只读公开展品；个人时间轴需要登录；个人星图严格仅拥有者可见。

```
python -m pip install -r requirements.txt pytest httpx
PYTHONPATH=. python -m pytest -q tests
node --check static/cosmos.js
```

前端依赖原有黑金风格，但无额外付费图表库，无新建 CDN 依赖。V12 的基础路线可在手机和桌面上渲染，不等于已部署到公网。外部来源内容的版权与鉴定仍由原始来源决定。
