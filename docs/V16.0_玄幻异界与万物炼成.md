# 万物博物馆 V16.0：玄幻异界与万物炼成

> 产品定位：真实世界的馆藏以来源和证据组织，虚构世界的馆藏以规则和创意组织；两者允许互相启发，但绝不能混淆。

## 1. 主要功能

1. **异界世界生成**：六大主题（星河仙庭、洪荒秘境、机械修真、深海龙宫、梦境荒原、幽冥古国），六种原创天道规则（灵气守恒、记忆抵押、因果倒写、万物修行、名字真形、梦境时间）。馆长可以命名世界、设定介绍及公开权限。
2. **万物炼成台**：从 18 种原料中任选两个，组合当前世界主题、规则和推演次数，通过可重复的 SHA-256 映射生成奇物名称、等级、神通、代价、禁忌、世界设定故事。无需接入外部模型，不用消耗 Token。
3. **虚实之门**：创作时可指定一个有权限查看的现实展品编号作为灵感；只记录引用 ID。若将来灵感藏品撤回公开或删除，其他访客不会看到其标题或编号。生成结果不抄写现实藏品标题，也不把灵感变成可证实的历史因果。
4. **异界藏馆**：只展示馆长主动公开的世界及其中已公开的奇物；私密作品不进入公共浏览。所有奇物本质上是既有 `exhibits` 中的原创虚构展品，能沿用现有评论、收藏、展厅和馆长档案。作品始终带显眼的「纯虚构／原创世界观」标记。
5. **异界星图 + 命运三分岔**：以 2D SVG 展示该世界奇物，点击节点可开启守护、献祭或封印三种互动虚构结局。结局为确定性原创叙述，不会自动影响真实收藏或私下记录选择。

## 2. 与原有项目的关系

- 新增侧边导航「玄幻异界」，黑金基调与紫蓝星雾视觉搭配；移动端增加「异界」快捷入口。
- 虚构奇物统一类别 `民间奇趣 / 原创与个人创作 / 世界观设定`，时间尺度保留 `时间不详` + `虚构世界纪年`。**不能将虚构纪年纳入真实历史时间轴。**
- 私人世界默认只对馆长可见；世界公开后，奇物仍各自保留私密状态，必须再由馆长手动公开。
- 世界改回私密会将该世界下**全部奇物同步设为私密**；重新公开世界不会自动公开奇物。
- 世界删除时一并删除该世界全部虚构展品；作品点赞和评论等既有引用随数据库关系删除。
- 从普通展品编辑接口编辑玄幻奇物时，服务器继续确保所属系列、领域、时间与虚构标记无法被修改为真实馆藏形态；私人世界作品也不允许经普通展品编辑接口公开。

## 3. API

| 方法 | 路径 | 权限 | 作用 |
|---|---|---|---|
| GET | `/api/fantasy/config` | 游客可读 | 获取世界主题、天道规则、炼材清单 |
| POST | `/api/fantasy/preview` | 游客可用 | 免费确定性生成奇物预览，不写数据库 |
| POST | `/api/fantasy/worlds` | 登录 | 创建世界（最多 30 个） |
| GET | `/api/fantasy/worlds?scope=public` | 游客可读 | 真实馆长公开世界 |
| GET | `/api/fantasy/worlds?scope=mine` | 登录 | 当前用户全部世界 |
| GET | `/api/fantasy/worlds/{id}` | 访客有权限 | 世界细节与可见奇物 |
| PATCH | `/api/fantasy/worlds/{id}/visibility` | 世界所有者 | 公开或关闭世界 |
| DELETE | `/api/fantasy/worlds/{id}` | 世界所有者 | 删除世界与其衍生作品 |
| POST | `/api/fantasy/worlds/{id}/forge` | 世界所有者 | 保存奇物（每世界最多 150 件） |
| PATCH | `/api/fantasy/relics/{id}/visibility` | 奇物所有者 | 修改单件奇物公开状态 |
| DELETE | `/api/fantasy/relics/{id}` | 奇物所有者 | 删除奇物与其通用展品 |
| GET | `/api/fantasy/relics/{id}/fate?choice=守护` | 有权查看奇物者 | 返回互动虚构分支结局 |

## 4. 创意与数据原则

- 这是玄幻世界观创作工具，不是宗教、历史或科学事实数据库。
- 不借用现成小说的角色、剧情与专有名词；系统产出的世界与文本为项目原创编写的规则组合，并不承诺排除同名巧合。
- 用户输入世界名、介绍也可能受版权/平台政策约束；若之后开放公网，需要审核、反骚扰、上传许可和举报机制。
- 前端对用户内容做 HTML 转义，所有管理 API 都通过 session 认证；服务端限制世界数量、奇物数量、字符长度与素材枚举。
- 如果未来追加大型语言模型生成，只能是显式选择功能，并继续保留「虚构」「真实来源」「AI 生成」三种独立标记。

## 5. 验收方法

解压/克隆项目并安装依赖，在根目录运行：

```bash
PYTHONPATH=. python -m pytest -q tests/test_fantasy_v16.py
node --check static/fantasy.js
node --check static/app.js
```

访问本机站点侧边栏「玄幻异界」，依次：无账号推演 → 登录创建私人世界 → 保存奇物 → 开放世界 → 开放单件奇物 → 游客查看 → 尝试修改权限/关闭世界 → 测试异界星图与命运分支。所有真实浏览器交互仍须手工验收。
