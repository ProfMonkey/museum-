# V10.0 分类体系设计

## 设计原则

万物博物馆不使用单一、互斥的大分类来容纳所有内容。每件展品由几个可组合的维度描述：

1. **内容系列**：藏品系列 / 民间奇趣。
2. **一级领域**：历史与考古、自然史、计算机、数码产品、网络文化等 32 个领域。
3. **细分类别**：随一级领域变化，提供更具体的对象类型。
4. **时间尺度**：用于快速筛选的宽时间范围。
5. **时间依据**：说明标签描述的是形成、制作、发布、发现、走红还是事件发生时间。
6. **年代原文**：保留馆方或用户所见来源中的原始写法。

## 两个大系列

- **藏品系列**：文物、艺术品、古董、珠宝、化石、自然标本、科技产品、书籍、游戏作品、科学资料等可被描述和追溯的对象。建议填写来源链接。系列本身不是“官方认证”或“已核验”标志。
- **民间奇趣**：网络热梗、奇怪网站、个人见闻、趣味知识、原创理论、用户作品和未必属于实体藏品的内容。

用户上传的内容仍然是用户贡献；选入“藏品系列”不代表博物馆替它背书。详情页会保留来源链接和用户手记。

## 时间尺度建议

| 标签 | 建议范围 | 典型内容 |
|---|---|---|
| 亿年前 | 约 1 亿年前及更早 | 地球演化、古老岩层、部分化石 |
| 百万年前 | 约 100 万至 1 亿年前 | 古生物、地质事件 |
| 远古与史前 | 约 1 万至 100 万年前 | 史前人类、环境与文化遗存 |
| 千年至万年前 | 约 1000 至 1 万年前 | 早期文明、史前遗存 |
| 近千年 | 约 100 至 1000 年前 | 中世纪与近世文物、手稿 |
| 近现代 | 约 30 至 100 年前 | 现代设计、早期电子产品 |
| 近30年 | 约 1 至 30 年前，不含最近一年 | 互联网、游戏、数码产品 |
| 最近一年 | 过去 365 天 | 新发布产品、最近走红的梗 |
| 此刻/实时 | 正在发生或实时更新 | 当前事件、实时榜单 |
| 跨越多个时期 | 多阶段演变或时间跨度很长 | 语言、文明、长期技术演化 |
| 时间不详 | 暂无可靠依据 | 不应凭猜测补年份 |

这些范围只服务于检索，不取代准确年代。对年代有争议的藏品应保留来源原文并选择“时间不详”或“跨越多个时期”。

## 迁移与兼容

启动时自动为既有 SQLite 的 exhibits 表添加 series、domain、time_bucket、time_basis、time_note 字段；旧 category 标签保留，旧类别会尽可能映射到一级领域。个人备份导出和 V2 恢复保留新增字段。
