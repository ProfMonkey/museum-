## 代码基线

- 仓库：ProfMonkey/museum-。main 基线 d688654，工作区初始无未提交修改。
- 发现尚未合并的 V42 搜索分支（PR #28），纳入 0d17641，保留统一搜索、隐私检查与 Windows 启动器。
- 本次修改不新增数据库迁移，不改变数据库路径、账号权限或原 API 的请求协议。仅 wonder_discovery.py 的功能展示文案更新；server.py 的变化来自既有 V42 搜索分支。

## 参考研究

| 参考 | 借鉴到本项目的做法 |
| --- | --- |
| [The Met](https://www.metmuseum.org/) | 按参观、展览、艺术等用户目的分组；首页优先展示作品。 |
| [Rijksmuseum](https://www.rijksmuseum.nl/) | 少量主要入口，大图引导进入馆藏和故事，次级工具逐层展开。 |
| [MoMA](https://www.moma.org/) | 明确的内容层级、作品名称和简短说明，减少功能列表式首页。 |
| [Google Arts & Culture](https://artsandculture.google.com/) | 将探索、游戏和个人收藏区分；保留醒目的搜索与分类浏览。 |
| [British Museum](https://www.britishmuseum.org/collection) | 首页及馆藏指南返回 403，未能直接验证其当前页面；没有把无法查看的视觉细节当作已完成研究。 |

## 实现

- 桌面侧栏：逛博物馆、我的收藏、趣味体验；其余工具放入一个默认折叠的“更多探索”。
- 手机底栏：发现、搜索、探索、发布、我的，共五个固定入口。
- 顶部藏品搜索与工具目录检索分开；保留 / 搜索快捷键、返回导航和显式发布操作。
- 首页：真实作品主视觉、四个快捷入口、真实公开藏品、可展开领域、世界名馆和三种互动方式。
- 32 个领域及全部原有细类、年代与系列数据保留；首页默认展示六个领域，其余手动展开。
- 藏品卡片、详情和关联区域的分类按钮统一进入专用搜索，携带领域、类别或年代。关键词和筛选可组合。
- 手机搜索筛选默认折叠；桌面默认展开。
- 将 38 份已有样式表的暗色声明迁移到共用浅色变量，合并同作用域内重复选择器和冲突声明；移除 features.css 中覆盖全站的第二套黑金主题。新 museum.css 负责新首页与响应式布局。
- 普通文字采用统一系统字体。保留藏品图片、模型与 3D 场景自身的颜色。
- 网页猴功能保留。新访客默认关闭动画，已有偏好继续有效；可从更多探索开启。
- 快速切页增加加载提示和过期渲染防护。

## 验证

- 原始 V42 基线：306 通过、17 失败。失败主要为历史版本号断言；另有整数与字符串执行 in 比较的测试错误，以及转盘主题断言尚未包含 V39 新增主题。
- 更新过期的界面文案及版本标记断言；修正私密藏品断言以按 ID 列表检查，转盘主题断言与现有八类配置对齐。保留原来的权限、撤回可见性与真实数据测试。
- 完整改造测试：`python -m pytest -q tests --disable-warnings`，323 通过、2 条既有弃用警告。
- 最终相关检查：搜索、导航、转盘、多用户、收藏及互动模块 28 项通过。
- 所有第一方 JavaScript 均通过 `node --check`。
- 真实浏览器：桌面约 1348×928；手机使用 390×844 iframe 验证响应式布局（滚动条内可用内容宽 375px）。没有把 iframe 检查称为实体手机测试。
- 浏览器逐项打开主要专业页面和原有 13 项互动入口，检查工具检索、折叠分类、搜索、组合筛选、详情与关联入口。
- 在隔离预览数据库创建明确标记的样例：两个公开、一个私密。搜索只返回两个公开记录，组合领域筛选后返回一个；验收样例及数据库已移除，不提交任何样例或用户数据。
- 注册、发布、编辑、删除、收藏及隐私权限由 HTTP 集成测试验证；浏览器检查游客界面与登录提示，没有使用用户真实账号。

## 变更文件分组

- `static/index.html`、`static/app.js`：全站框架、首页、导航与分类跳转。
- `static/feature-map.js`、`static/features.js`、`static/monkeys.js`：入口注册表、原有互动入口及动画设置。
- `static/unified-search.js`、`static/unified-search.css`：统一搜索、移动筛选、系列显示名称。
- `static/museum.css` 及其余组件 CSS：浅色主题、排版和响应式整理。
- 各功能 JS：面向用户的名称、页面标题与入口文案更新，保留原逻辑。
- `static/assets/museum/`：两张来自 The Met 官方开放馆藏的公有领域作品，来源见同目录 README。
- `wonder_discovery.py`：使用统计中的功能显示名称。
- `tests/`：对应新的界面名称与现有版本，修正基线中的过期断言。
- `deploy/start-public-preview.ps1`：启动器改为拉取 main 的最新代码，保持原数据目录。
- `scripts/preview.py`、`package.json`、`.gitignore`：可重复的隔离预览；不打开用户原数据库。
