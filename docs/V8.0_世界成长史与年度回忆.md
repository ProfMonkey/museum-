# V8.0 · 我的世界成长史与年度回忆

## 设计选择

不再给侧边栏增加一个独立入口：在回忆剧场内部切换「成长史」标签，与既有片库共用数据、播放器和配乐。

## 来源口径（API /api/growth/overview?year=2026）

- 新增展品：`exhibits.created_at`，仅当前登录用户；按创建时所属类别统计。
- 新增展厅：`halls.created_at`；默认展厅是系统为新账号自动创建，也计入该年份。
- 观看足迹：`memory_views.first_at`，只在主动开启记录并查看展品详情后存在；**只计首次被记录年份**，无法还原每一次观看的日期。
- 私人影片：`memory_reels.created_at`；保存年度影片也会成为成长记录。
- 跨界路线：`atlas_saved_routes.created_at`；只有按下保存路线后存在，不把仅看过的路线记为完成。
- 收藏书签不记到年度分布，因为现有数据库没有准确时间字段。
- 删除的记录不回溯，避免「伪造记忆」。

## 年度电影

当年自建展品及当年首次记录的可访问展品按可核实时间排序，去重后最多 40 幕，空集合不生成影片。当前权限检查使用统一 `read_exhibit`。直接预览调用已有回忆剧场播放机；保存时调用 `/api/memories/reels`，不新增影片表。

## 功能优先级

复用 `/api/insights/summary` 的聚合数据；每项建议至少需要 5 位周期活跃用户及 5 张累计偏好票，未达到时显示样本不足。符合条件时区分「优先修复体验」「值得深入打磨」「持续观察」，仅作为人工开发计划参考。**投票是累计口径、使用量为选定近 7/30/90 天，二者不是同一时间窗口，不能直接用于因果分析。**

## 隐私与限制

- 仅本人登录可读，全部数据在服务端按 `user_id` 限制；他人隐藏或删除的展品过滤。
- 不采集用户位置、音频或原始输入，不引入新事件表。
- 导出的 JSON 是私人数据，请用户自行保存。
- 站点未部署公网；浏览器侧播放仍须用户点击，浏览器可能阻止自动发声。
- 为了简单部署继续使用 SQLite。公网生产建议数据库备份、迁移和审核，不能直接把开发服务裸露公网。
