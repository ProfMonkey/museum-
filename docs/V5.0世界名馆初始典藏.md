# V5.0 世界名馆 · 初始典藏

## 目标

新用户进入万物博物馆时，不必等待社区用户上传内容，就能直接浏览一组有真实馆藏来源的精选作品。此模块与“发现广场”的用户投稿分开，馆藏本身不会被伪装成用户原创内容。

## 当前首批内容

首批 17 件精选作品来自三个提供公开数据接口的馆藏机构：

- 大都会艺术博物馆（The Metropolitan Museum of Art）：绘画、版画、挂毯、古代埃及文物、中国佛教雕塑、法国铠甲等。
- 芝加哥艺术博物馆（Art Institute of Chicago）：修拉、梵高、莫奈的代表作品。
- 克利夫兰艺术博物馆（Cleveland Museum of Art）：中国山水、欧洲宗教题材作品。

首批精选不是三个馆的完整数据库。未来可以扩展搜索和更多机构，但必须先确认数据来源、图片开放许可与 API 使用条件。

## 数据来源与图像规则

- The Met：`https://collectionapi.metmuseum.org/public/collection/v1/objects/{objectID}`。只有 `isPublicDomain=true` 时才展示其图像。
- Art Institute of Chicago：`https://api.artic.edu/api/v1/artworks/{id}`。只有 `is_public_domain=true` 且存在 `image_id` 时，才构建官方 IIIF 图像地址。
- Cleveland Museum of Art：`https://openaccess-api.clevelandart.org/api/artworks/{id}`。只有 `share_license_status=CC0` 且存在官方图像链接时才显示图像。

页面保留原馆作品页和许可政策链接。若官方 API 无法访问，页面会立即显示本地策展元数据，并异步尝试更新；不会用虚构图片冒充原作。图像采用馆方 HTTPS 地址，不会被复制到本项目服务器。

## 收入个人博物馆

1. 用户点击“收入我的博物馆”。
2. 后端验证作品 ID 是否属于当前精选目录。
3. 将标题、创作者、年代、媒材、所属机构、许可状态、馆方来源写入当前用户自己的 `exhibits` 表。
4. 新记录默认 `visibility=private`，不自动发布到公共广场。
5. `world_museum_imports` 通过 `(user_id, catalog_id)` 唯一约束避免重复收入；不同账号各自独立。
6. 原馆图像仍由原馆托管，来源和许可信息写入展品档案。

## 隐私与边界

- 访客可以浏览目录和馆方来源；未登录用户不能收入个人馆藏。
- 收入的馆藏默认私密；用户可在个人博物馆里决定是否公开。
- 目录元数据与用户原创投稿分开呈现。
- 外链目录中列出的卢浮宫、大英博物馆、荷兰国立博物馆和美国国家美术馆目前只是官方入口，不代表其作品已被导入本站目录。
