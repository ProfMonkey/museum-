# 万物博物馆 V40.0｜信息架构与全站关联重构

**开发状态：尚未部署公网。** 本轮不调用、不启用 GitHub Actions；新回归测试需要在项目本机执行。

## 1. 为什么这次不继续堆功能？

万物博物馆已有发现广场、世界名馆、时间线、星图、随机奇遇、万物转盘、展厅工坊、互动实验、架空世界、文明合作和个人系统等多个模块。单个模块可以很好玩，但如果用户不知道入口在哪、分类是什么、下一个该去哪里，功能数量就会变成使用成本。

V40 的核心是三件事必须统一：
- **分类**：东西应该归到哪里？
- **导航**：我现在在哪、怎么回去？
- **关联**：我可以从当前内容继续做什么？

## 2. 统一导航层级

侧边栏统一为：
1. **发现与检索**：发现广场、世界名馆、万物雷达、当代新奇
2. **分类与关联探索**：万物时光、随机奇遇、万物星图
3. **收藏与创作**：心动收藏、我的博物馆、展厅工坊
4. **互动与体验**：万物转盘、万物实验室、互动玩法、命运接力
5. **世界与故事**：玄幻异界、平行宇宙、活体博物馆、谜案馆、万物碰撞机、文明演化、文明考古局
6. **合作与交流**：联合展厅、文明大使馆、遗产交换站
7. **个人与系统**：回忆剧场、功能热度、通知中心

顶部增加返回上一页、回到首页和当前功能分类。导航历史仅保存在当前页面内存中，不会向服务器上传。回退栈限制为 40 项，避免无限增长。

## 3. 功能地图不再只是目录

功能地图包含三层：
- **按目标进入**：用户可直接选择“找一件藏品”“按时间探索”“发现新奇事物”“整理我的收藏”“建造个人展厅”“体验互动玩法”“与别人合作”。
- **按分类找藏品**：系列、年代、领域与细类作为独立筛选维度。领域列表按需展开；旧版本遗留的分类单独标注为“历史兼容分类”，仍可用于检索，不假装它们已经完成标准归并。
- **按功能名/用途搜索**：继续使用功能搜索框，但明确说明它只搜索功能入口；具体藏品需使用分类浏览器或发现广场。

分类来源于 `static/taxonomy.js` 的受控词表：
- 32 个领域；
- 223 个可检索分类标签，其中部分为旧版兼容标签；
- 11 个年代桶；
- 2 个面向用户的系列标签（“藏品系列”“用户上传系列”）；为避免破坏旧数据与 API，后者目前仍兼容旧存储值“民间奇趣”。

点击领域、细类、年代或系列，直接跳转发现广场并应用筛选。选择新分类时重置此前不相关的筛选，避免用户不清楚为什么结果为空。用户若要组合多个维度，可在发现广场继续交叉筛选。

## 4. 藏品卡片与档案成为导航节点

卡片显示领域、细类、年代，并将这些信息变为可点击筛选项。档案里的系列、领域、细类、时代同样可点击。
- 点击领域：显示该领域的公开内容；
- 点击细类：按领域 + 细类筛选；
- 点击时代：按该年代继续探索；
- 点击系列：回到相应内容系列。

这些操作只修改检索条件，不修改藏品本身的分类和内容，也不改变所有权、公开状态或来源。

## 5. 全站关联路径

功能地图维护统一的下一步关系表，并供每个主要页面使用。页面底部展示最多三个相关去处：
- **真实藏品 → 时间线 → 星图/考古**；
- **收藏 → 个人展厅 → 联合展厅**；
- **互动实验 → 游戏 → 命运接力/转盘**；
- **玄幻世界 → 平行宇宙/碰撞机 → 文明演化**；
- **文明演化 → 文明大使馆 → 遗产交换站**；
- **谜案 → 奇遇/考古 → 真实藏品**。

这些是明确的功能导航建议，不会自动创建内容、改动权限或替用户执行操作。关联表集中在 `static/feature-map.js`，避免每个页面随意生成不同入口。

## 6. 技术修改

- `static/index.html`：统一侧边栏分类、增加返回按钮与分层面包屑，更新版本标记。
- `static/feature-map.js`：任务入口、领域/细类/年代/系列分类浏览器、旧分类兼容区、统一功能关联图。
- `static/app.js`：有限返回历史、当前分类面包屑、每个主要页面的下一步导航、卡片与档案的可点击分类筛选。
- `static/style.css`：桌面/手机分类浏览器、任务入口、下一步导航和面包屑样式。
- `server.py`：健康检查版本更新为 40.0。
- `tests/test_v40_navigation.py`：新增导航层级、分类动作、关联图与回退栈的本地回归检查。
- `scripts/check_local.py`：将 V40 回归测试纳入 `--quick`。

## 7. 本地验收

在项目目录执行：

```powershell
python scripts/check_local.py --quick
python scripts/check_local.py --js-only
```

建议手工验证：
1. 打开“找功能”，先用“按目标进入”找到模块，再用功能搜索找一个具体入口。
2. 展开“按领域与细分类别浏览”，选择一个领域/细类，确认发现广场的筛选条件和结果一致。
3. 点一件藏品卡片上的领域、细类或年代标签，确认不会误打开档案。
4. 打开档案，点系列/领域/细类/时代，确认筛选生效。
5. 在“文明演化”页面底部进入“文明大使馆”，再进入“遗产交换站”；使用“返回”逐级回到上一个功能。
6. 在手机宽度下检查顶部回退按钮、功能入口卡片、年代标签与领域折叠列表。
