# 万物博物馆 V9.0：当代新奇与虚拟展厅工坊

## 当代新奇

新增统一入口“当代新奇”，包含热梗档案、数码产品、游戏专区。三者仍使用统一展品模型，可登录后保存为私人展品，随后加入个人展厅、回忆剧场或跨界探索。

- **热梗档案**：只读读取梗Wiki公开 API（`https://cnmeme.wiki/api/v1/public/memes`），支持关键词搜索和分页。来源内容由外部服务提供，无法访问时明确显示错误，不伪造实时热榜。保存时记录公开 API 详情 URL、词条 slug 和标签；梗Wiki公开 API 不代表素材获得额外转载授权。
- **数码产品**：整理 Raspberry Pi、Framework、Steam Deck、DJI、Arduino、Nothing 等官方入口，并尝试读取 Hacker News 前台科技动态。精选入口不冒充实时销量榜；实时动态仅在外部 API 成功时显示。
- **游戏专区**：整理 OpenTTD、0 A.D.、SuperTuxKart、Luanti、Veloren、Endless Sky、itch.io 免费游戏和 GitHub 开源游戏等入口；另有本地馆藏记忆配对小游戏。游戏的具体平台、授权与可用性以原项目页面为准。

## 展厅工坊

- 内置 9 套项目原创 SVG 平面图：古典长廊、中央庭院、环形展厅、星芒展馆、沉浸长廊、科技实验室、游戏街机馆、自然花园馆、黑盒实验空间。
- 可下载当前原创 SVG 图纸。
- 登录后可创建私密展厅，将图纸应用到现有展厅；应用布局会保存到原有 `hall_items` 布局，不删除展品，也不更改展厅公开/私密权限。若展厅为空，会尝试将最多 12 件本人藏品加入展厅。
- 轻量沉浸漫游支持上一件/下一件、卡片翻面和图片放大。
- 可选真实 WebGL 三维展厅使用 Three.js（MIT）从 jsDelivr CDN 加载；如果 CDN 被网络策略阻断，轻量展厅仍可用。三维墙面展示当前展品标题/类别纹理，点击墙上展品可切换档案，拖动旋转视角、滚轮缩放。
- 互动实验台提供摆锤长度、角度和动画速度控制。它是教学演示，不是高精度物理仿真。

## 免费素材来源与许可

- 本项目原创 SVG 平面图由项目自行绘制，可在本项目中直接使用。
- [Poly Haven Models](https://polyhaven.com/models)：素材标注 CC0；使用前仍应检查具体条目。
- [Smithsonian Open Access](https://www.si.edu/openaccess)：仅将明确标记为 CC0 的项目用于可再利用内容。
- [Sketchfab glTF / downloadable models](https://sketchfab.com/features/gltf)：每个模型授权不同，须逐项检查 CC0、CC BY、NC、ND 等条件。
- [PlayCanvas Model Viewer](https://dev.playcanvas.com/products/viewer)：免费开源查看器，MIT；外链工具不等于本站托管或代理模型文件。
- [Kenney assets](https://kenney.nl/assets)：逐包确认许可说明。
- [Wikimedia Commons](https://commons.wikimedia.org/)：每个文件独立标示许可，使用前阅读文件页。

## 隐私、真实性与限制

- 外部 API 仅在用户打开对应页面时请求，不会自动采集用户的私人内容。
- 用户保存外部项目时默认 `visibility=private`，需要主动发布才会进入公开广场。
- 外部 API/图片可能被限流或跨域策略阻断；接口不可用时会显示提示。
- 3D 模式依赖外部 CDN 和 WebGL；低性能设备可以继续使用 CSS 沉浸展厅。
- 目前未部署公网；要让不同网络的用户访问，仍需部署服务器、域名、HTTPS、备份和内容治理。
