# 万物博物馆 V25.0｜✨ 万物命运接力 · 我的今日奇遇卡

## 核心概念

从 V24 的「一次抽取」升级成真正的**2–5 个阶段顺序抽取**。

馆长可以挑选自己已经创建的不同转盘，把 **吃什么 → 去哪玩 → 做什么 → 探索什么** 组织成一条路线。每个阶段都要通过后端单独进行公平抽取，结果逐步解锁，不存在假的社区内容或预设中奖结果。

例子：

> 第 1 站：🍜 吃什么 → 米线  
> 第 2 站：🧭 去哪里 → 博物馆  
> 第 3 站：🎨 做什么 → 摄影  
> 第 4 站：🌌 探索什么 → 黑洞

所有结果来源于用户自己选择、且当前存在有效选项的转盘；不会把网站作者编造的选项伪装成真实馆长上传的东西。

## 页面

左侧新增「✨ 万物命运接力」，并从 V24 万物转盘与首页增加快捷入口。

馆长可以创建路线，选择每一站真实的私人转盘，单独点击「🎲 抽取下一站」，观察卡片逐步解锁。中途离开再次进入可以继续抽取；已完成的卡片可保存 PNG 图片。每个账号最多保存 30 张卡片。

**游客也能试玩**四站免费的系统示例奇遇。每一站调用 V24 无状态服务端抽取接口（`POST /api/wheels/preview`），游客示例数据只保存在当前页面运行状态，不生成真实馆长、作品或在线人数，也不产生分享链接。

## 抽取公平性

- 每站当前目标转盘必须至少有 2 个**仍有效**选项。
- 选择该转盘的 `secrets.randbelow` 随机抽取，遵循它在 V24 中已经设置的「不连续重复」开关。
- 抽取同时写入此转盘原有的私人抽取历史（20 条上限），V24 与 V25 的防重复行为因此一致。
- 从同一个转盘创建两站不被允许，避免「连续随机」里无意义的重复设置。
- 每个阶段真正落库后才向前端返回结果，动画仅负责表现，不干扰概率。

## 隐私与可撤回的公开卡

- 每张命运奇遇卡 **默认 PRIVATE**，只有所有者能够查看进度、查看结果、删除或管理。
- 完成全部阶段后，作者可以**主动公开**，生成随机独立的分享链接（安全随机 token）。
- 分享链接指向 `/adventure/<share_token>`，服务端直接渲染可在社交平台或浏览器打开的 HTML 卡片。用户自己保存的 PNG 图片也是私人文件，**保存图片不等于公开**。
- 作者撤回公开后，旧 token 立即作废；重新公开将获得新 token。
- 如果某一站原本抽中的馆藏后来变为 PRIVATE 或被删除，所有者页面、公开 API 和独立分享网页都会自动改成「已撤回的馆藏」，不再显示标题或来源。原始馆藏标题没有作为文本快照放入奇遇卡。
- 手动输入的纯文本若作者主动公开奇遇卡，表示同意把这些文字分享出去；它们不依赖馆藏来源。
- 对共享卡页面用户文本做 HTML 转义，响应声明 CSP、禁止搜索索引、设置 no-store 缓存控制，不接受任意脚本。

## 新增数据表

`wonder_adventures`：`owner_id`、`title`、`visibility`、`share_token`、时间戳。

`wonder_adventure_steps`：`adventure_id`、顺序、关联转盘、当时的场景标题、选中的选项 ID、选项性质、手动标签或者实际藏品 ID、抽取时间。

外键删除策略确保转盘或选项删除后数据不被错误地指向其他人的后来新内容。

## API

| 路由 | 说明 |
|---|---|
| `GET /api/adventures/config` | 类型信息与上限 |
| `GET /api/adventures` | 当前登录用户的奇遇列表 |
| `POST /api/adventures` | 创建 2–5 站私人路线 |
| `GET /api/adventures/{id}` | 查看本人真实奇遇及进度 |
| `POST /api/adventures/{id}/advance` | 在数据库事务中抽取下一站 |
| `PATCH /api/adventures/{id}/visibility` | 完成后明确发布／撤回 |
| `DELETE /api/adventures/{id}` | 删除个人奇遇卡，不删除转盘或馆藏 |
| `GET /api/adventures/share/{token}` | 仅已发布且已完成的分享信息 |
| `GET /adventure/{token}` | 独立公开 HTML 奇遇卡 |

## 安全与限制

本模块是私人娱乐与灵感决策工具，非付费抽奖或博彩，也不是线下餐馆实时推荐。网页仅展示用户自己的选择、有效的公开来源和明确区分的游客演示。

完成的卡片不能继续抽取；需要改变路线应创建另一张卡片，而不能改写公开分享记录。公开分享链接虽然不被搜索引擎索引，但**拥有链接的人可以访问**；不能把 token 当作对已经分享出去的图片或截图的撤回机制。

本版 CI 覆盖 Python 多用户测试和所有第一方 JS 文件的语法检查。真实浏览器端到端、移动端 Canvas 图片导出、分享平台预览以及长时间负载测试仍需单独验证。
