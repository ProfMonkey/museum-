# V11.0 · 万物分类路径与可解释关联网络

## 一、用户体验

不新增重复侧栏入口。在任何展品详情中点击 **「分类与关联图」** 即可查看：

- **分类路径**：内容系列 → 一级领域 → 细分类别（沿用 V10 字段）。
- **时间路径**：时间尺度 → 时间依据；保留来源中的具体年代原文。
- **万物关系图**：焦点展品居中，金色实线表示馆长解释过的关系，灰蓝虚线表示系统根据同标签/同分类得出的相似性推荐。
- **逐层漫游**：默认一层，可扩展两层；点击节点即可换一个焦点，也可随时回到原展品档案。
- **自己创建关系**：起点展品属于当前用户时，填写目标展品编号、关系类型和不少于 8 字的解释。支持删除本人提交的关系。

## 二、真实性边界

**馆长手动关联 ≠ 历史事实验证。** 页面明确标记“馆长提出、未经平台核验”。系统推荐仅依据共同标签/共同细类/共同领域，不猜测古代艺术与现代科学之间的因果关系，也不声称两物具有历史影响链条。

自动推荐不由大模型即兴编造，解释文字直接列出共同属性。路由最大 2 层、返回最多 32 个节点，并对候选搜索设置上限。

## 三、权限与隐私

沿用原有展品可见性约束，不改变收藏、公开或私人权限：

- 匿名用户和其他账号只能看到公开展品节点。
- 当前账号可看到自己的私人展品与其关联，但不会泄露他人的私人内容。
- 新增人工关系要求起点为本人藏品；目标必须是公开展品或本人有权访问的私人展品。
- 只有创建关联的账号可以删除它；数据库使用外键及唯一约束。
- 所有前端自由文本输出先进行 HTML 转义。

## 四、API

- `GET /api/exhibits/{id}/connections?depth=1`：返回焦点分类路径、节点、关联依据。
- `POST /api/exhibits/{id}/connections`：人工添加一条有解释的关系；登录且拥有源展品才可提交。
- `DELETE /api/exhibits/{id}/connections/{link_id}`：删除本人创建的关联。

所有 API 复用原始 SQLite 用户、展品与认证体系。新增 `exhibit_links` 表，旧展品不迁移、不复制；删除展品时关系通过外键级联清理。

## 五、后续迭代（未假装实现）

- 可信关系审核：对“影响/启发”等因果主张要求出处和双方确认。
- 直接把馆方未收藏作品作为网络节点（目前世界名馆藏品收入个人馆后才成为普通展品节点）。
- 长路径搜索与更大图规模检索：建议分离图数据库/搜索索引后再做。
