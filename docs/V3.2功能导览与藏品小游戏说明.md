# 万物博物馆 Wonder Atlas V3.2：功能导览与藏品小游戏

## 本版目标

V3.2 不再单纯堆叠入口，而是让每个页面都说明“这里能做什么、如何开始、哪些内容会联网保存”。13 项特色工程的页面顶部新增三步玩法说明；模块名称改成更通俗的中文，并在总览页增加基于真实公开藏品的小游戏。

## 一、主导航说明

| 入口 | 作用 | 怎么用 |
|---|---|---|
| 发现广场 | 查看全站公开展品 | 搜索关键词、按分类筛选、选择最新/热门排序；打开展品详情后可以收藏、点赞、评论或关注馆长 |
| 随机奇遇 | 不输入关键词，随机遇见公开展品 | 阅读随机选中的展品，觉得有意思就打开档案或收藏，再点击“下一次奇遇” |
| 心动收藏 | 保存别人发布的公开展品 | 在展品详情点击收藏；回到此处继续查看。它与自己的馆藏分开 |
| 我的博物馆 | 管理自己的展品和展厅 | 发布展品、创建展厅、设置公开/私密、自由布展、导入旧版备份或导出数据 |
| 通知中心 | 汇总点赞、评论和关注提醒 | 点击用户名访问馆长主页，点击展品链接回到相关内容，或将通知标为已读 |
| 13 项特色工程 | 进入专门的探索、协作和互动工具 | 点击统一黑金封面；每个页面顶部先看“这里可以做什么”，再按步骤操作 |

## 二、13 项特色工程的具体用途

### E01｜关联探索
从一件公开展品跳转到其他展品。实线表示馆主明确建立的关系；虚线是系统按分类/标签提供的候选，不代表已验证的事实。只有起点展品的馆主可以保存正式关联。

### E02｜奇物调查
馆主为自己的公开展品发起一个问题。其他用户可以分别提交证据线索或个人假设。馆主可以变更调查状态并说明理由；状态、猜想和证据不自动等同于真相。

### E03｜不同角度看
多位用户可以为同一公开展品留下不同解读，例如科学、艺术、设计、个人记忆等角度。观点独立保存，彼此不会覆盖。

### E04｜时光记录
给公开展品追加历史事件、发生时间、描述和可选来源。界面区分事件发生时间与上传时间。投稿内容仍需自行核验。

### E05｜互动故事
创建一个简化的双分支故事：写开场、设置两个选择、分别写结局。访客选择不同分支会看到不同结局。当前不是自由拖拽节点的可视化编辑器。

### E06｜身边的奇物
将公开展品关联到城市或街区，并说明为什么值得探访。当前版本只保存城市/片区文字，不接地图服务、不读取 GPS、不鼓励发布私人住宅精确位置。

### E07｜网页小猴子
在网页内选择 1–6 只猴子，切换安静/猴山/关闭模式。可拖动或点击互动。猴子只在浏览器网页内活动，不会跨应用控制 Windows 桌面。

### E08｜奇物接龙
用户发起一条故事链，其他用户依次选择新的公开展品，并写明它如何接续上一段。每一段都会显示展品、接力理由与贡献者。同一账号不能连续接力。

### E09｜小猴导览
选择主题，系统按公开展品已有的标题、分类和简介组织导览卡。当前是确定性模板组合，不调用 AI，不会把缺少来源的内容说成已证实事实。

### E10｜动手玩展品
调整光照滑块，观察发光植物视觉模型变化，并可恢复初始条件。该模型用于交互演示，不代表真实生物实验数据。

### E11｜一起逛博物馆
创建参观房间并分享房间码。其他已登录用户可加入、查看同步展品和发送文字留言。当前以轮询同步，无音视频功能。

### E12｜藏品来源
查看展品来源、作者/发现者署名、许可声明、补充说明和修订历史。来源内容由馆主填写，不代表平台已独立核验；发布前仍应确认版权与转载授权。

### E13｜我的兴趣地图
根据当前用户自己的馆藏分类，在浏览器中生成数量分布。不是人格诊断，不额外上传画像，不自动公开。

## 三、藏品游乐场：新增三款小游戏

### 1. 猜盲盒
从真实公开藏品中抽取一件，隐藏标题与分类，显示模糊封面（没有图片时显示文字线索），并提供四个真实藏品标题。玩家猜中正确标题后揭晓完整档案；答对加 10 分。至少需要 4 件公开藏品。

### 2. 藏品闪记
展示一件真实藏品约 3 秒，随后隐藏并给出四个标题选项，玩家需要找回刚才出现的藏品。需要至少四件公开藏品。

### 3. 同类配对
系统展示一件目标藏品和三件候选，暂时隐藏分类，玩家要选出同一分类的藏品。需要馆藏里有足够的分类多样性。

小游戏得分、答题轮数和正确率保存在当前浏览器，不上传服务器，也不属于全站排行榜。游戏题目来自服务端真实公开藏品，不会伪造社区内容。

## 四、创意实验：两种没有标准答案的玩法

### 1. 奇物碰撞台
从服务器公开展品中抽取两件东西，尽量选择不同类别。用户需要思考两者之间可能有什么联系。登录用户如果以自己发布的公开展品为起点，可以进入 E01 关联探索，把关系和理由保存到服务器；如果起点不是自己的展品，只能作为探索灵感，不能越权替别人确认关联。

### 2. 未来考古舱
选择一件真实公开展品，设想一千年后的考古学家会如何解释它，并写下自己的假说。当前假说只保存在当前浏览器的 localStorage，不会上传到服务器，也不会显示给其他用户。

## 五、数据保存范围

- **服务器保存**：账号、公开/私密展品、展厅、点赞/评论/关注、特色工程中已接入的悬案、观点、时间事件、故事、地点文字、接力、同行房间和来源护照等。
- **当前浏览器保存**：网页猴子的数量/模式、未来考古舱假说草稿和保存的本地假说、小游戏战绩（已玩轮次、答对率和积分）。
- **纯交互/临时状态**：小游戏当前题目与答题过程、碰撞台当前配对、实验室滑块当前值等。
- 只有部署在同一服务器上的用户才会共享服务器数据。localhost 只对本机可访问；跨城市访问仍需自行部署公网服务、HTTPS、备份与审核机制。
