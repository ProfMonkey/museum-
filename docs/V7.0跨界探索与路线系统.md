# 万物博物馆 V7.0：万物跨界探索（2026-10-26）

## 功能目的

把「随机奇遇」和「跨界探索」整合为**一个主导航入口**，避免多个页面重复做推荐和随机浏览。让用户从馆藏古董、名画、科技主题或社区真实展品出发，沿标注原因的链接探索别的领域。

## V7.0 新功能

1. **跨界探索**：22 个由编辑维护的主题节点、17 个馆方精选作品节点、最多最近 400 件公开用户展品节点。来自用户的私密展品从服务端检索阶段就排除。
2. **四条跨领域预制路线**：古代铠甲→金属→材料→芯片；古画→色彩→数字影像→计算→AI；海浪艺术→航海→天文→航天；中世纪织物→编织与算法。这些是策展的跨学科阅读顺序，不宣称作品直接导致技术发明。
3. **自定义起止节点和最大步数**：最短可解释路径搜索（宽度优先），无路可达就如实显示未找到，不凭空添加节点或关系。
4. **逐站参观**：每站展示实际馆藏或真实用户展品、来源链接、跳转原因、上一站和下一站。
5. **保存路线**：注册用户可以将经过服务器验证的路线保存到自己的账号里。路径上限 9 个节点、最多 60 条，重复保存同一路线仅更新标题。
6. **公开路线链接**：可复制起点与终点参数；访问时重新运行权限与路径计算，不会信任旧缓存或强制输出过期展品。
7. **从展品出发**：世界名馆作品卡和**公开**社区藏品详情页加入「跨界探索」，直接跳转新页面；用户的私密藏品不产生公开索引。
8. **功能热度**：沿用 V6 聚合统计，新增 `atlas_explore` 维度；不会增加一个新的数据采集系统。

## 有关关联的三种口径

- **策展关联**：由项目维护者编辑，表达适合连续阅读的主题联系；不等于严谨事实证明。
- **人工确认**：原展品馆主在既有「万物虫洞」创建的显式连线；尊重原方向，不无故将其变为双向。
- **关键词建议**：使用可检索标签或标题为公开投稿匹配相关主题，不能当作经过核验的事实。

## 数据与隐私

- 系统不复制开放博物馆的作品产权；馆藏图片仍由原馆托管，并遵守其开放访问标志。
- 最多扫描最近 400 件公开用户投稿，避免低成本自托管服务器对全部投稿进行无限全图查询；后续如达到规模，应替换为索引与分页机制。
- 不提供私密投稿关联，不允许假路径保存；用户取消公开后，涉及该展品的已保存路线将标记为失效，不再返回其内容。
- 路线仅能由所有者查看/删除，匿名用户可以看公开主题与名馆信息。
- 路线分享只保存起终点，不包含任何登录凭据。

## 暂时不做

- 不把「语义相似」叫作经过证实的文化史因果关系；没有接入大模型自动证据核验。
- 不上传私密浏览足迹到公共旅程；V4 回忆剧场仍需主动开启记录。
- 不重复另建一个社区、评论系统、随机奇遇数据库或功能投票系统。
- 未部署公网、未达到课程 23000 行源码要求，正式发布需安全审计与端到端验收。
