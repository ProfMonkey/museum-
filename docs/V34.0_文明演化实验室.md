# 万物博物馆 V34.0｜文明演化实验室：一件藏品引发八个时代的历史

> 产品定位：这是一套**公开可解释的虚构文明玩具规则 + 用户原创编年史 + 只读反事实比较**，不是准确的社会/经济/政治/人口/自然预测器，也没有后台自动文明模拟或虚构真人投稿。

## 🏛 从 V33 的碰撞世界生长出文明

1. 某位真实馆长已经在 V33「万物碰撞机」发表自己的双物件架空世界，两件原始藏品都仍真正公开。
2. 世界**原作者**可以从这两件物件中选择一个「文明种子」，写下新的虚构文明名称与宣言，创建**默认私密**的文明草稿。
3. 每个 V33 世界最多有 **六个文明**，延续既有的每世界最多六文明设定，且只有世界所有者有权在自己世界中添加；不允许普通访客擅自替别人建造文明。
4. 文明有五个统一的游戏指标（均为 0–100）：知识、物资、生态、凝聚、文化。创建时全部为 50。
5. 作者逐轮决定文明政策，亲自撰写每轮历史篇章。每个文明最多八轮。写下至少两轮以后，馆长才可以主动公开给游客；追加/撤回一个篇章会将整个文明恢复私密草稿，防止未经作者重新审核就公开改写的历史。

**原创性**：不是用户输入一段提示词后伪装成系统产生了真实历史；所有历史事件与世界观文字都有真实作者，所有数值变化由已公开规则计算而来。可以把其作为收藏、互动与原创世界的融合型小作品，而不保证“全世界其他产品绝对没有”。

## 🧭 六种文明策略（规则完全确定）

| 策略 | 五维变化 (知识、物资、生态、凝聚、文化) | 风格 |
|---|---|---|
| 研究未知 | +13, −6, −4, −1, +1 | 在资源和生态压力下发展知识 |
| 拓荒生产 | +1, +14, −10, +1, −1 | 物资增长伴随生态压力 |
| 文明交流 | +3, −3, −1, +10, +8 | 凝聚与文化 |
| 生态修复 | +2, −5, +14, +2, +1 | 主动恢复生态 |
| 艺术与传承 | +3, −5, 0, +6, +13 | 增强文化 |
| 封闭防御 | −5, +5, −3, +7, −8 | 牺牲开放性换取短期维稳 |

游戏模型附加：来自 V33 双物件世界的架空法则会对部分策略中的**一个维度**施加明确 +3 或 −3 的修饰。效果表 `civilization_engine.LAW_EFFECT` 随 `GET /api/civilizations/policies` 一起公开，模型版本 `MODEL_VERSION=1`。

计算流程：
1. 从上轮完整数值开始，或从所有指标均为 50 的初始状态开始。
2. 取对应策略的公开基础变动，并加入适用的 +3 / −3 虚构世界法则修正。
3. 将每一维裁剪至 0–100，回传精确的 **实际变化量**，而不是未裁剪的理论变化量。
4. 若有一维低于 25，生成显式的「危机」**游戏事件标签**；否则若有一维不低于 80，标记「繁盛」；其他情况仅标记「新抉择年代」。
5. 将完整数值快照、作者原创历史、所选政策和真正录入时间存入本馆的 SQLite。

没有引入随机数据、自动网络爬虫、真实国别建模或科研算法。该模型仅服务于可解释的原创玩法，**不能据此做现实政策判断**。

## 🔬 核心新功能：历史分岔显微镜

游客无需注册，只要文明当前公开并且全部原始来源仍合法，就可以：

1. 阅读真实馆长已经写下的前 **2–8 轮**完整历史。
2. 选择其中一轮曾经实际记录的决策（比如第 3 轮「拓荒生产」）。
3. 将这一轮改为另一个政策（比如「生态修复」）。
4. 系统使用相同、公开、纯函数式的规则，从改变的历史节点开始重算；**其后全部仍按照原作者记录的政策路线前进**。
5. 结果并排呈现「馆长原版历史」与「假如当时选择另一条路」的五维最终指标、数值差异与逐轮模型事件标签。

这是一项**只读即时演算**：没有改动真实存档，不会替作者发布新的虚构历史，不会给原作者的作品附上“经证明的客观后果”。重新执行同样输入必得同样的虚构规则结果。

## 🔐 世界来源与撤回保护

- 只允许 V33 碰撞世界**真正原作者**在自己仍已发布的世界里创文明。
- 每次公开查询、发布、增加新篇章、反事实计算都重新核验：
  - V33 母世界依然公开；
  - 母世界**修订版本仍与文明出生时相同**，防止原作者撤回母世界再发布新设定后，旧文明“悄悄恢复公开”；
  - 母世界的**两件**原始藏品都仍公开；
  - 作为文明种子的原始藏品确实来自这两件藏品；
  - 现实藏品附属的玄幻世界、创作工坊、沙盒也都允许公开，复用 V29 `PUBLIC_SCOPE` 的已有权限规范。
- 失效时，公开列表与详情中没有旧藏品、旧世界标题或旧作者编年史；作者的清单也只显示通用锁定占位，不能从它取得原始标题、历史篇章。作者仍可删除自己的无效文明草稿。
- 外部游客只可看到作者主动批准的公开文明；只有作者本人可以创建、追加/撤回历史、发布、暂停公开或删除整个文明。
- 不声称“AI 自动生成真实历史”，也不包含对其他真实用户私密内容的可访问链接。

## 🛠 新增 API

| 路由 | 作用 |
|---|---|
| `GET /api/civilizations/policies` | 显式规则、初始状态、模型版本、六策略及六类架空世界修正 |
| `GET /api/civilizations/worlds` | 当前用户自己已发布的合法 V33 碰撞世界，以及可用的两件原始种子 |
| `GET /api/civilizations` | 匿名可浏览的真实作者公开文明画廊 |
| `GET /api/civilizations/mine` | 本人文明草稿、已公开作品与失效来源的安全占位 |
| `POST /api/civilizations` | 创建只属于本人 V33 世界的私密文明（最多六个/世界） |
| `GET /api/civilizations/{id}` | 当前合法公开文明；未公开时仅作者可读 |
| `PUT /api/civilizations/{id}` | 作者修订文明名称与宣言；新文案恢复私密，须重新人工发布 |
| `POST /api/civilizations/{id}/turns` | 作者追加一次明确策略与亲笔历史篇章，并撤销旧公开状态 |
| `DELETE /api/civilizations/{id}/turns/latest` | 作者撤销最后一轮历史，回到私密草稿 |
| `POST /api/civilizations/{id}/publish` | 至少两轮后原作者再次主动公开 |
| `POST /api/civilizations/{id}/unpublish` | 作者暂停公开 |
| `DELETE /api/civilizations/{id}` | 作者删除文明及篇章，原始碰撞世界不受影响 |
| `GET /api/civilizations/{id}/counterfactual?turn=&policy=` | 在允许查看的当前合法历史上，重放一个只读分支的全部剩余轮次 |

## 📦 工程文件

- `civilization_engine.py`：可复现的独立文明规则纯函数和版本。
- `civilization_lab.py`：SQLite + FastAPI，世界原作者校验、六文明/八轮限制、显式历史、反事实视图。
- `static/civilizations.js` / `static/civilizations.css`：深空金色文明起源、五维进度图、历史卷轴、事件编写控制台、左右反事实对照，移动端兼容。
- `tests/test_civilizations_v34.py`：新增 12 组集成和确定性规则测试，包括来源撤回、父世界版本变更、上限、玩家/馆长权限与历史重放。
