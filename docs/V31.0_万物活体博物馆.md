# 万物博物馆 V31.0｜万物活体博物馆

**一件展品不必停留在发布的那一天：让真实馆长在原始藏品上持续补充观察年轮。**

## 功能概览

- **🌱 原始藏品观察年轮**：只有原作者能为自己的藏品追加观察/里程碑/修正/新发现四类事件，每件最多 120 条（包含撤回记录）。事件包含标题、内容、观察日期（不得是未来日期）、可选 HTTP(S) 原始来源链接、服务器实际录入时间。追加式记录不支持偷偷编辑；原作者可以撤回自己的记录。
- **🌍 万物脉搏**：按最近 30 天公开且仍获准展示的馆长录入记录，统计条数、涉及展品数、领域分布。没有数据就显示空；不伪造实时宇宙动态。服务端最多统计最新 10,000 条符合筛选的记录。
- **✦ 公开变化广场**：展示至多最近 28 条真实馆长录入的可见记录，关联仍然公开的原始展品，而不是假的实时抓取数据。
- **♡ 观察清单（站内追更）**：登录用户可以关注最多 120 件目前确实公开的藏品。关注时，历史记录不算未读；关注后馆长新增的有效记录计入未读数量，可以标记已阅、取消关注。这**不是**系统级推送、不是后台监听外网。
- **⇄ 双时空观察室**：输入两件当前确实公开的藏品 ID，查看各自最近 30 条馆长观察年轮。仅客观并列，不做因果归因，不假装来源已由平台核实。
- **移动端与链接**：独立「🌱 万物活体博物馆」导航，手机快捷入口；`?living=<ID>` 可打开原始藏品的公开年轮。

## 信息真实性分层

每条年轮事件清楚展示：

- **观察日期**：由馆长填写；这不是原始作品的形成年代。
- **提交时间**：服务端 UTC 时间戳；据此排序公开最新记录。
- **外部证据链接（可选）**：馆长提交的 HTTP(S) URL，显式标记为 **「馆长提供来源链接（未经平台核验）」**；没有来源则标注 **「馆长自述观察（未附外部来源）」**。
- **变化性质**：观察、里程碑、修正旧认识、新发现；无 AI 的虚构新闻事件，也不对外声称实时自动同步。

## 严格隐私边界

使用已有 V29 的实时公开权限谓词 `PUBLIC_SCOPE`，包括原始公开属性以及所属玄幻世界、创作工坊和沙盒的隐私状态：

1. **只有原作者可增加/撤回自己的年轮**。私密藏品可以由作者自己记录，但访客、其他登录用户和公共变化广场都看不到。
2. **来源撤回**：原始藏品删除或变私密后，公开年轮返回 404；公开信息流与脉搏汇总不计入这些事件。
3. **已关注的来源撤回**：关注清单保留不包含旧标题、说明、事件内容的锁定占位项，未读数清零；用户仍能取消关注。
4. **双时空对照**：必须两件作品都仍合法公开，任何一件撤回后接口不返回局部的旧内容。前端重绘时重新核验已显示的对照，避免客户端缓存泄漏。
5. **撤回单条记录**：该条即刻从公开信息流、年轮列表、站内未读与汇总统计中隐藏。数据库保留内部撤回标记；删除原藏品则数据库外键级联清除记录。

## API 合同

| Endpoint | 作用 |
|---|---|
| `GET /api/living/feed` | 最近 28 条真实有效公开观察记录 |
| `GET /api/living/pulse` | 最近 30 天公开记录/藏品/领域真实计数 |
| `GET /api/living/exhibits/{id}` | 本人私密或所有人可见的公开年轮 |
| `POST /api/living/exhibits/{id}/entries` | 作者追加一条完整观察记录 |
| `POST /api/living/entries/{entry_id}/withdraw` | 作者撤回本人一条记录 |
| `GET /api/living/watchlist` | 登录用户的私人追更与未读数 |
| `POST /api/living/exhibits/{id}/watch` | 关注当前公开藏品 |
| `DELETE /api/living/exhibits/{id}/watch` | 取消本人关注 |
| `POST /api/living/exhibits/{id}/seen` | 将当前可见更新标记为已阅 |
| `GET /api/living/compare?left_id=&right_id=` | 两件当前公开藏品并列对照年轮 |

## 数据与规模

- `living_entries`：原作品 ID、原作者 ID、类别、标题、说明、观察日期、来源链接、服务器录入时间、撤回状态。
- `living_watches`：登录用户与公开原藏品 ID、关注时间、`last_seen_id`。未读数只计入原作者新增且没有撤回的合法记录。
- 普通 SQLite 部署，带有效索引，每用户最多关注 120 件，每件最多 120 条观察，公共 feed 28 条、领域统计样本上限 10,000 条。

**明确尚未实现：** 按来源 API 自动抓取变化、可信事实复核、Web Push/移动系统通知、语义原因推理、生产级并发压测和真实浏览器视觉回归。这一版本是可用的真实互动年轮，而不是号称已经接好所有宇宙数据源的监控平台。
