# 万物博物馆 V33.0｜万物碰撞机：蝴蝶效应与平行世界谱系

**现实物件是素材，架空法则是火花，世界的故事只由真实馆长创造。**

这是新模块「⚗️ 万物碰撞机」，不以虚构内容冒充历史事实，不模拟其他馆长，不认为此玩法全世界独家。本模块的特色在于：**一对有来源、可追溯的真实馆藏，经不同创作者的不同“宇宙法则”，形成可互动、有署名、可改写但不抢夺原作的多元世界谱系。**

## 🌌 玩家体验

- **万物碰撞反应堆**：从真实当前公开的藏品里选择 A / B 两件不同物件，分别显示目前可访问的标题、分类和真实馆长署名。一次搜索最多展示 40 个真实来源。
- **六种架空法则**：时间逆流、大小互换、记忆交易、物质交换、世界融合、因果倒置。点击「⚡ 点燃碰撞」可见基于「两件藏品 + 法则」生成的确定性、可复现创作提示。
- **蝴蝶效应 / 双分支未来**：原创馆长写出世界前提、两个选择和各自不同的故事结局。游客进入世界后选择 A 或 B 路线，展开对应的作者原创文字；不需要在事实层面证明“会发生”。
- **真实的分支选择统计**：登录用户对每个已公开世界只保留一次当前选择；再次选择可修改，统计 A/B 两个真实账号的计数。未登录游客可以本地查看结局，但不会伪造投票。
- **🪐 改写平行历史**：登录馆长可以以当前公开作品为灵感进行二次原创。必须保留这两件原始公开展品，但新的世界法则、完整前提、分支与结局由改写者自行创作。产生默认私密的独立草稿，显示当前原始作品的公开来源（前提是父世界仍公开）。
- **同源平行谱系**：同一对真实物件，无论 A/B 顺序如何，都会检索最多最近 40 座当前合法公开的不同世界，让游客观察同样素材在不同馆长的创作中如何分叉。只有真实存在的作品才显示，不捏造世界和热度。

### 一个虚构实例（不是社区已有内容）

A：云南米线；B：一座古老钟楼；法则：**记忆交易**。

馆长可以创作世界《被吃掉的时间》，设定「记忆可以换取时间」。

游客选择「守护全部记忆」：时间消失但所有故事永不褪色。

或者选择「将记忆交易出去」：人类重新获得钟声，却彻底忘记了食物的味道。

两个结局只属于该创作者的**原创虚构假设**。

## 🛡️ 隐私及创作边界

- **作者与草稿**：每名登录馆长最多创建 24 个实验世界。所有新世界、改写世界默认为私密；只有作者点击发布后才能出现在公共世界广场。
- **来源双重实时核验**：两件原始展品都必须真正公开，且所属玄幻世界、创作工坊、沙盒等权限允许公开。任一端变私密或删除，公开世界及谱系目录立即隐藏该世界，公开详情返回 404。
- **避免旧文字泄漏**：当任一原始端撤回公开后，作者自己的预览中**同时隐藏两侧标题、完整世界前提和两个结局**。不保留外部原作品名称、描述或封面快照。源对象引用以可置 NULL 的外键保存。
- **独立原创而非内容复制**：改写时只沿用两件来源 ID 和父作品可见关系；不复制原作者的标题、前提、故事结局。原作者没有自动授权全部故事的复制。
- **版本变化重置投票**：作者编辑、撤回公开时，自动恢复私密草稿、递增修订号、清空旧版投票。重新公开后从零开始统计该新版本。
- **私人选择**：每人每个公开作品最多一条分支记录；公共接口只暴露聚合数量，不显示投票用户身份或账号清单。
- **创作真实性**：此模块没有使用大模型编造来源、假装引用真实 AI 结果。自动创意开场只是一条公开透明、可复现的规则模板。

## 🛠️ API

| 接口 | 作用 |
|---|---|
| `GET /api/collisions/laws` | 六个架空法则及提示模板 |
| `GET /api/collisions/sources?q=` | 当前合法公开的真实藏品搜索 |
| `GET /api/collisions/preview?left_id=&right_id=&law=` | 为两件公开藏品输出确定性创作开场 |
| `GET /api/collisions` | 当前合法公开的作者原创实验广场 |
| `GET /api/collisions/mine` | 登录馆长的私密/公开个人世界 |
| `GET /api/collisions/echoes?left_id=&right_id=` | 同源世界谱系（仅公开且来源有效） |
| `POST /api/collisions` | 创建默认私密的原创世界 |
| `GET /api/collisions/{id}` | 当前公开世界或本人私密草稿 |
| `PUT /api/collisions/{id}` | 作者修改草稿/公开世界；新版本变私密、清空投票 |
| `POST /api/collisions/{id}/publish` | 作者确认两件来源均公开并主动发布 |
| `POST /api/collisions/{id}/unpublish` | 作者撤回公开，重置私人版本和旧投票 |
| `DELETE /api/collisions/{id}` | 作者永久删除世界，原始藏品不受影响 |
| `POST /api/collisions/{id}/choose/a` 或 `/b` | 登录游客选择或切换个人分支 |
| `POST /api/collisions/{id}/remix` | 保留同源引用但原创重新编写完整的新世界；默认私密 |

## 📦 工程实现

新增 `collision_universes.py`（SQLite 三表）、`static/collision.js`（SPA）、`static/collision.css`（响应式深空黑金美术）、`tests/test_collision_v33.py`（新增集成测试）。

数据库：
- `collision_worlds`：拥有者、双公开原始对象 ID、架空法则、完整原创世界说明、两个分支选择/结局、发布状态、修订号、可见父世界引用。
- `collision_choices`：实验 ID、登录用户 ID、本人当前分支，联合主键唯一。公开仅展示 A/B 两个聚合计数。

## 🔋 不再消耗 GitHub Actions

仓库 `.github/workflows/ci.yml` 已关闭 `push` / `pull_request` 自动触发，仅保留 `workflow_dispatch`。此版本在开发、创建 PR 或合并时**均不运行 GitHub Actions**。本地手动验收可运行：

`python scripts/check_local.py --quick`（目前 quick 只包含 V32 模块）；

`python -m pytest -q tests/test_collision_v33.py`（V33 专项）；

`python scripts/check_local.py`（整套测试与 Node.js JS 语法）。

以上命令是建议的**本地**运行路径，不能在未运行时宣称测试通过。真实浏览器端到端、用户负载和作品分支反滥用测试也应另行验收。
