# 万物博物馆 V18.0｜文明演化模拟器

> WONDER ATLAS · The Age of Civilizations
> 本功能是有所有者、权限与年度快照的**原创虚构文明模拟器**，并非真实历史、科学人口预测、资产系统或自动托管游戏。

## 一、为何增加此模块

V16 允许创造世界与法则，V17 允许创造最多六个文明并由两个真实账号自愿共创故事。
V18 让文明拥有**可保存、可分岔、可回看的模拟发展史**。

- 每个馆长可对自己创建的文明开辟最多三条独立纪元。
- 每次只推进一年；不会在离线时擅自推进，也不会替其他玩家作决定。
- 每年四个政策可选：**开垦、求知、守护、通商**。
- 保存粮储、学识、生态、秩序、文化、能量（0–100）与虚构人口（100–1,000 万）。
- 根据用户选择、既有世界天律和确定性事件模拟下一年的状态。
- 记录第 0–100 年的快照、政策、事件与时间；达到 100 年停止推进。
- 可从已经发生的历史年份创建平行支线，不覆盖原先的年历。
- 用折线图展示历年六项指标；在纪年档案里阅读每次决策及重大事件。
- 默认私密；必须在世界和文明都公开后，由年历拥有者**单独主动公开**。
- 撤回文明或世界公开时，年历的发布授权同步撤回；重新公开不会自动恢复。

## 二、交互路径

启动本地站点 → 玄幻异界 → ⏳ 文明演化。

1. 在「我的世界」创建世界，再去「万界会盟 → 文明档案」创建文明。
2. 打开「文明演化」，选择自己的一座文明并填写纪元名称。
3. 点击「开始模拟」创建第 0 年的原始快照。
4. 选择开垦/求知/守护/通商，推进一个完整的虚构年。
5. 点击已发生的某一年，另开一条命运支线；最多三条。
6. 需要分享时，先公开世界和文明，随后明确点击「公开这条虚构年历」。
7. 游客切换到「公开纪元」，只阅读已经授权的虚构历史，不能修改。

本版本沿用既有 FastAPI + SQLite + 原生 JS/CSS，不使用额外在线 AI 服务，不消耗额外模型 token。
没有私自创建用户、篡改世界原始天律、修改其他用户的文明或转移资产。

## 三、确定性演化设计

实现：`evolution_api.py` 的 `evolve(old, policy, law, timeline_id, year)`。

- 四种政策分别施加明确的资源增减。
- 每年都计算粮储消耗、能量消耗、生态修复与文化积累。
- 世界六大已有天律分别在对应政策下引入可见的模拟代价/收益，但**不修改天律文本**。
- 重大事件由 SHA-256 对 `timeline_id | year | law | policy` 确定性映射；给定完全相同的状态和输入，结果保持一致。
- 基于粮储与秩序计算每年受限的虚构人口变化；各项指标夹在 0–100，虚构人口夹在 100–10,000,000。
- 每次模拟结果立即写入 SQL 唯一键 `(timeline_id, year)` 的不可覆盖快照；写入前使用 `BEGIN IMMEDIATE` 串行化同一数据库的创建、分岔与推进。
- 如需重新演化，必须创建其他支线；不提供历史快照就地修改。

注意：这些规则是**可玩的、透明的简化公式**，不代表真实社会科学模型，后续可以在兼容旧年历的前提下推出新模拟版本。

## 四、API

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| GET | `/api/fantasy/evolution/config` | 政策、上限、说明 |
| GET | `/api/fantasy/evolution/civilizations?scope=mine\|public` | 可访问文明 |
| GET | `/api/fantasy/evolution/timelines?civilization_id=N` | 对应文明的可见纪元 |
| POST | `/api/fantasy/evolution/timelines` | 创建第 0 年快照 |
| GET | `/api/fantasy/evolution/timelines/{id}` | 查看纪元与完整快照 |
| POST | `/api/fantasy/evolution/timelines/{id}/advance` | 选择政策推进一年 |
| POST | `/api/fantasy/evolution/timelines/{id}/fork` | 从既有年限复制状态开新分支 |
| PATCH | `/api/fantasy/evolution/timelines/{id}/visibility` | 主动公开/撤回 |
| DELETE | `/api/fantasy/evolution/timelines/{id}` | 删除自己的一条纪元 |

公开视图和私人视图都标注 `fictional=true`。只有会话认证的文明所有者有写权限，
无权访问的私人纪元统一返回 404。数据随文明或世界删除级联删除。

## 五、测试与当前边界

新增 `tests/test_evolution_v18.py`，覆盖：
初始虚构状态、匿名用户读写权限、他人无法操作、公开门槛与撤回、年限资源上限、
100 年停止、分岔独立、最多三条、级联删除以及推演确定性。

运行：
```bash
python -m pytest -q tests/test_evolution_v18.py
python -m pytest -q tests
node --check static/evolution.js
```

规模化模拟性能与部署环境安全。当前不宣称完成这些验收。
