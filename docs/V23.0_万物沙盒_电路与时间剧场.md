# V23.0 · 万物沙盒：电路积木与万物时间剧场

这一版拓展了「⚙ 万物皆可玩」，新增第四个子页 **🧱 万物沙盒**，将科学积木和历史／虚构叙事收进同一个可以直接交互的创作平台。

## ⚡ 一、理想电路积木

任何用户（包括游客）可以打开公开作品、选择串联或并联、调节电源电压（0.1–24V）以及 2–4 个电阻（每个 1–1000Ω），点击按钮由后端重新计算。

服务端输出：
- 等效电阻（Ω）
- 总电流（A）
- 总功率（W）
- 每个电阻的电流、电压、功率

页面绘制教学用途 SVG 电路示意图和逐项读数。*这不是实际电路设计工具：* 不包含短路保护、导线与接触损耗、真实电源容量、温升等现象。禁止据此进行实体接线或危险实验。

## ⏳ 二、万物时间剧场

馆长可以不用写代码，在可视化表单里搭建 **3–10 幕时间故事**，每幕包含：
- 年份（公元前用负数，不能使用第 0 年；最大支持公元前约 10 亿年，最晚公元 3000 年）
- 事件名称与文字故事
- 真实性标签：**史料待核／个人记录／原创虚构**
- 只有「史料待核」事件才可填写 HTTPS 参考链接

时间轴必须由远及近排列。游客可以在时间卡片之间导航、跳转和阅读，每幕的标签始终可见。用户给出的所谓参考链接未经平台独立核验；用户自己编写的未来架空文明永远明确标记为虚构。

## 🏛 三、接入真正的个人博物馆

使用「🧱 万物沙盒」编辑器创作并保存后，后台同时创建一个**真正归本人所有、默认仅自己可见**的博物馆藏品。每位用户最多有 12 件沙盒作品；原有 V22 奇物问答、生命沙盘、旋律机及其他收藏功能均保留。

项目所有权、更新、删除、发布和撤回由后端检查。用户在沙盒中主动公开时，项目与关联藏品一起发布；取消公开时都隐藏。如果用户使用旧有藏品编辑页面将关联展品改为私人，沙盒项目的单独公开许可同步撤回，以后重新公开普通藏品也不会偷偷恢复沙盒发布授权。删除沙盒项目只删除该项目创建的附属展品，不删除他人的来源或原有个人收藏。

## 代码结构

- `sandbox_api.py` — 两种受限类型的参数验证、SQLite 持久化、计算 API、发布授权与详情权限。
- `static/sandbox.js` — 电路参数预览、动态图纸、时间剧场、积木编辑器。
- `static/sandbox.css` — 深色金色博物馆设计和手机自适应。
- `static/play.js` — 「万物皆可玩」第四个页签。
- `server.py` — API 注册与关联藏品私密化撤权。
- `tests/test_sandbox_v23.py` — 计算、身份、历史真实性分类、异常值、外部链接、删除级联以及撤权测试。

## 主要 API

- `GET /api/play/sandbox/config`
- `POST /api/play/sandbox/preview`（无需登录，参数受限）
- `GET /api/play/sandbox?scope=public|mine`
- `POST /api/play/sandbox`
- `GET /api/play/sandbox/{id}`
- `PUT /api/play/sandbox/{id}`
- `PATCH /api/play/sandbox/{id}/visibility`
- `DELETE /api/play/sandbox/{id}`
- `POST /api/play/sandbox/{id}/simulate`（访问已公开电路或本人的私人电路）

## 验收边界

使用 `python -m pytest -q tests` 和 GitHub Actions 的 `node --check static/*.js` 检验。自动化单元与接口测试不等同于实际浏览器端到端测试、专业电气工程验证、公网安全审计或者真实手机硬件测试。

### 后续设想

可继续做「时空博物馆地图」：同一组公开藏品在地理、时间、关联线索三种维度探索；真实地点与虚构世界需要保持显著区别，地理数据和外部站点不得自动被当成可信认证来源。
