# 万物博物馆 V42.0｜零成本公网预览（Windows）

## 启动方式

1. 下载并双击 START_PUBLIC_PREVIEW.bat。
2. 首次运行会自动下载 V42 源码、安装 Python 依赖和 Cloudflare Tunnel 程序。
3. 等待窗口出现 https://xxxx.trycloudflare.com。
4. 这个 HTTPS 地址就是当前公网预览网址，启动器会尝试自动打开并复制到剪贴板。

## 需要什么

- Windows 10/11 64 位。
- Python 3.12（安装时勾选 Add Python to PATH）。
- 能访问 GitHub 与 PyPI 的网络。

不需要购买域名、不需要 Cloudflare 账号，也不需要 GitHub Actions。Cloudflare Quick Tunnel 官方说明：
https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/do-more-with-tunnels/trycloudflare/

## 重要限制

- 这是临时公网预览，不是 24 小时托管。网站运行在你自己的电脑上，电脑必须开机且保持联网，启动窗口不能关闭。
- 关闭窗口或网络中断后，网址失效；重新运行会生成新网址。
- 数据库与上传文件保存在本机 %LOCALAPPDATA%\WonderAtlas\source\data，正常重启不会自动删除。不要删除这个目录。
- 这是公开网址，任何拿到网址的人都能访问，网站当前允许访客注册。请勿上传身份证、密码、隐私照片或其他敏感资料；只把网址分享给你愿意邀请的人。
- 这不是稳定生产部署：Cloudflare Quick Tunnel 没有 uptime 保证，适合先体验与验收。要长期稳定开放，需要单独配置长期主机/命名 Tunnel。
- 第一次安装依赖需要联网，时间可能较长。启动器只会运行本仓库的 V42 开发分支。

## 停止

在启动窗口按 Ctrl+C，公网预览随即结束。再次运行启动器会生成新的临时网址。
