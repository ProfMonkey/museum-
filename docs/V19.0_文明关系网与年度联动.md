# 万物博物馆 V19.0：文明关系网

V19 为 V18 的原创虚构文明年历增加双方同意的交流关系。每位馆长分别决定是否将获准的关系应用于自己未来某一年；不会改动其他馆长的世界规则、资产或历史快照。

## 四种关系

- 学术交流：学识 +5，能量 -2。
- 文化共鸣：文化 +6，秩序 -1。
- 联合勘探：粮储 +3，生态 -2。
- 星门议事：秩序 +4，文化 +1。

关系发送后等待对方同意；未被接受就没有演化效果。每个文明最多四条生效关系，每对文明历史最多四次邀请。账号最多十个待答复邀请。模拟年度仍需要本人点击推进，不会自动影响对方文明。

## 权限与历史

任何一方关闭世界或者把文明设为私密，现有关系永久撤回；重新开放不会自动恢复。曾经写入个人虚构历史的影响类型得以保留，但不会在公开档案里暴露另一方撤回的文明名称。每一年保存不可覆盖状态，并保持 V18 旧数据的兼容性。

## 接口

- GET /api/fantasy/relations/config
- GET /api/fantasy/relations/civilizations
- GET /api/fantasy/relations?scope=mine|public
- POST /api/fantasy/relations
- PATCH /api/fantasy/relations/{id}
- GET /api/fantasy/relations/available?timeline_id=N
- POST /api/fantasy/evolution/timelines/{id}/advance 可选 relation_id 参数

页面入口：玄幻异界 → 文明演化 → 文明关系网。项目依旧本地运行，没有上线公网。

## 测试

执行 python -m pytest -q tests 以及 node --check static/relations.js。新增 tests/test_relations_v19.py 覆盖双方审批、权限、撤回、历史快照、跨文明影响与数据清理。浏览器端到端、多人并发及正式部署仍需另行验收。
