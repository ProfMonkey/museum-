# 万物博物馆 V6.0：万物雷达、开放馆藏与功能热度

## 产品方向

万物博物馆不是只收古董或艺术品的数字画廊。分类同时覆盖过去、现在和未来：古董珠宝、绘画书画、钱币、古代文明、陶瓷、古籍、历史文物、科技发明、AI 与机器人、航天宇宙、自然化石、矿物宝石、建筑设计、时尚、摄影、游戏、互联网奇物、流行文化、音乐、生活发现与原创理论。

## 新增功能

- **世界博物馆导航**：按领域分组的官方馆藏入口，包含艺术、古董珠宝、亚洲艺术、自然历史、科技工程、摄影影像、数字档案和当代科技趋势。目录是外链导航；只有明确接入的馆方 API 才标记为开放数据来源。
- **跨馆开放馆藏搜索**：尝试检索 The Met、Art Institute of Chicago、Cleveland Museum of Art 的实时馆藏。支持中英文常见关键词映射。只在馆方 API 标记 Public Domain / Open Access / CC0 时显示图像；搜索依赖外部网络。
- **当代新奇雷达**：可选科技热榜、AI、机器人、芯片、量子、生物技术、互联网奇物、航天与宇宙。Hacker News 热榜和 NASA 图像 API 是外部实时源，无法连接时明确提示，不伪造热榜数据。
- **一键私藏外部发现**：将雷达条目保存为个人展品，默认私密；保留原始链接，限制外部图片 URL 的主机范围，防止把任意远程图片当作开放素材。
- **功能热度与用户投票**：登录用户可对功能选择“喜欢 / 一般 / 需改进”；每个账号每项功能一票，可更新。统计打开次数、后续操作、活跃用户数和投票分布。
- **产品分析最小化**：只存功能名、动作类型、账号 ID 和时间戳；不存搜索词、展品 ID、私人内容、访问网址或 IP。页面只返回聚合统计，不展示个人行为轨迹。
- **分类扩展**：公共发现和新建展品表单增加 30 多个类别。首页只展示常用快捷分类，完整分类放在下拉菜单，避免按钮堆满页面。

## 数据来源与版权

- The Met Open Access：<https://metmuseum.github.io/>
- Art Institute of Chicago API：<https://api.artic.edu/docs/>
- Cleveland Museum of Art Open Access：<https://www.clevelandart.org/open-access-api>
- Smithsonian Open Access：<https://www.si.edu/openaccess>
- Europeana APIs：<https://www.europeana.eu/en/apis>
- Rijksmuseum Data Services：<https://data.rijksmuseum.nl/docs/search>
- NASA Image and Video Library API：<https://api.nasa.gov/>

目录入口和外部趋势源不等于本站拥有其内容。每件作品的许可应以原始记录为准；私人收藏不应被误认为可公开转载或商业使用。

## 产品热度如何解释

不把访问量直接当成喜欢程度。访问次数衡量发现度，完成操作衡量实际使用，明确投票衡量主观偏好，改进票用于定位摩擦。开发优先级应结合三者、访谈和任务成功率判断，避免只追逐点击量。

## 运行与测试

Windows 双击 `run.bat`；本地访问 `http://127.0.0.1:8000`。需要访问外部 API 才能加载实时趋势与开放馆藏搜索；网络不可用时官方链接目录仍可用。

```bash
python -m pytest -q tests
node --check static/app.js
node --check static/features.js
node --check static/memories.js
node --check static/world-museums.js
node --check static/wonder-discovery.js
```

这是教学与自托管开发工程，不等于已经完成安全审计的生产级服务。公网部署前应加固认证、速率限制、备份、内容审核、隐私声明与数据保留策略。
