# 万物博物馆 V4.0：回忆剧场 · 设计与验收记录

## 用户体验

1. 登录 → 回忆剧场 → 主动开启“浏览足迹记录”（**默认关闭**）。
2. 到发现广场点击某一件展品的详情；只有打开展品详情会记录，列表浏览不会记录。
3. 回忆剧场按最近观看排序显示去重的展品、时间、所属分类、观看次数。可筛选、勾选、移除、清空。
4. 勾选几件想重看的藏品，命名回忆影片，选择 3 种原创合成器背景配乐或无声。
5. 点击“预览”进入全屏风格剧场，按播放按钮后开始自动翻页和配乐；支持上/下一幕、暂停、全屏、切换时长、加载自己的本地音乐文件。
6. 点击“保存我的影片”，把片名、展品 ID 顺序、配乐类型存入账号，跨浏览器访问**同一服务器**即可重放。**没有输出成 MP4**，这里是实时幻灯片剧场，不是视频文件生成器。
7. “偶遇旧日奇物”随机带回一个自己曾看过的展品，不会变成新的推荐流。

## 实现与隐私

- `memory_views` 每用户每展品只存一条记录，维护首次观看、最后观看、次数。
- `memory_reels` 每用户保存影片标题、参与展品的 ID 列表和所选音乐类型。浏览记录和影片只对账号所有者开放。
- 所有访问展品信息的 API 都重新检查公开/私密权限。原作者撤回、删除或隐藏公开展品后，非作者的回忆影片不再泄露该展品。
- 音乐使用 Web Audio API 在**当前浏览器本地**合成，不需要收费音乐 API，不下载任何商业曲目。
- 用户也可播放自己选择的音频文件；文件不会上传服务器、不会保存至账号，关闭网页后需重新选择。
- `prefers-reduced-motion` 时禁用动态镜头推进，减少眩晕风险。
- 录制开关保存在本地浏览器 `localStorage`，按账号 ID 区分；开启需主动点击，不是全站默认跟踪。
- 用户能清空全部记录；已保存的影片是独立列表，需单独删除（界面给出提示）。

## 与其他功能的关系

- 不新增重复的发布、搜索、评论、收藏系统。由**查看展品详情**产生足迹，以个人馆藏/公共公开藏品为素材，回忆页只负责整理和播放。
- V3.2 原有 13 特色工程、网页猴、小游戏和双用户共用服务器均保留。
- 本版没有上线公网服务器，仍需自行部署并配置 HTTPS。

## 可复现验收

- 后端测试：`python -m pytest -q tests`。
- JavaScript 语法：`node --check static/app.js` 与 `node --check static/memories.js`。
- 浏览器手动验收：两账号独立历史、开启后浏览产生足迹、关闭后不再增加、隐私撤回后影片隐藏、切换音轨、全屏、导入本地音频。
- 跨浏览器音频解码支持情况因操作系统而异；无法播放时可切回内置配乐。
