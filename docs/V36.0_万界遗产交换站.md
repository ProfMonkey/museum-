# 万物博物馆 V36.0｜万界遗产交换站

> 两位真实馆长，可以为各自拥有的真实公开藏品共同策展；双方分别撰写自己的文化解释并独立同意公开。藏品与版权归属从未改变，礼物只是虚构文明世界的**象征性展示**。

## 核心特色

V35「万界文明大使馆」已经允许两位 V34 原创虚构文明馆长通过真实邀请、亲笔国书、双重审批建立公共外交纪事。V36 以这座双方已经公开的使馆为前提，进一步提供「真实藏品 × 架空外交」的原创联合展。

**完整创作流程：**

1. 馆长 A 与馆长 B 已通过 V35 双人真实邀请，各写一封外交信，各自批准同一版本；来源的两座 V34 文明、V33 世界和其引用的所有真实藏品仍公开。
2. 任一位合作馆长在自己的 V35 公开使馆中创建文化互赠草稿，选择 A 和 B **分别真正拥有且目前公开**的各一件真实原始展品，并填写联合展示主题。
3. 双方分别从自己的账号撰写自己的藏品文化解释（12–680 字）。任何人都无法替另一方写故事；编辑任一解释或共同题目都会使整个联合展恢复私密草稿。
4. A、B 各自独立批准**同一编辑版本**。只有双方都批准，联合文化遗产才出现在公共画廊及可分享页面。
5. 登录游客可以领取一次虚拟文化交流护照章。每个账号每个版本最多统计一次，内容编辑或撤回后旧章归零。它不是实物游览、真正的国家签证或产权认证。

同一使馆最多创建 10 项文化互赠。任何一方可以随时撤回公众访问或永久终止单项互赠；**不会删除、移交或变更任何原始馆藏的所有权。**

### 虚构示例（不是已有真实用户作品）

- 原始馆藏 A：真实馆长 A 发布的《云南米线观察图鉴》
- 原始馆藏 B：真实馆长 B 发布的《古老的钟楼》
- 假想世界：由两位虚构文明创作者签署的「记忆之国 × 时间之城」外交史
- 馆长 A 自述：米线承载着人们共同的记忆。
- 馆长 B 自述：钟声是跨越时间的文化符号。
- 联合展：《记忆与时间互赠礼物》

这种故事只是两个真实用户对真实馆藏所做的**原创架空策展**，绝不表示原藏品被卖出、捐赠、借出、邮寄或获得现实世界官方认证。

## 🔒 实时权限与双人同意

- **严格复用 V35 验证器**：`embassies.py` 在挂载时通过 `app.state.embassy_public_validator` 暴露其**原本的**双人审批、原始 V34/V33 版本、公开真实源物品与国书作者验证逻辑；V36 **不重写、不绕过**该权限边界。
- **每次公共读取都重新核验**：V35 使馆已撤回、作者书信变化导致撤回审批、V34 文明更新、V33 世界变私密、任一关联源展品改为私密、双方审批撤回，公共文化互赠立即返回 404 或从列表消失。
- **两位藏品真实所有权**：A 物品必须由 V35 使馆发起馆长本人发布；B 物品必须由受邀馆长本人发布。两物品必须是当前真正公开、不同的原始藏品，遵守 V29 `PUBLIC_SCOPE`（玄幻世界/创作工坊/沙盒隐私一并过滤）。
- **无来源内容快照**：存储的只是关联展品 ID 与双方原创策展文本，每次展示从数据库读取当前有效标题/类别/封面。若任一原始来源不可用，**即使是合作成员**，本项目详情也遮蔽旧标题、两方说明与背景，只有锁定占位。
- **对等审批**：`a_note` 只可由馆长 A 修改，`b_note` 只可由馆长 B 修改；每次修改强制新版本、撤销旧双方投票、恢复私密。各方只能批准自己的份额，不得替另一方投票。
- **使馆版本过期**：每项互赠记录创建时的 V35 使馆版本号。如果 V35 原外交纪事内容变化，即使后来再次公开，此项遗产仍须由真实参与者「重新核验来源」并重新获得两个批准，**不会自动复活**。
- **礼物不改变所有权**：整个模块没有更新 `exhibits.user_id`、没有任何产权转让 API，也不产生现实金融收益。所谓“护照”只记录用户主动领取的站内虚拟纪念章。
- **真实用户、无模拟流量**：公共画廊、互动计数只取数据库真实用户操作，不会编造用户评价、访问人数或不存在的历史新闻。

## 📦 数据与 API

`cultural_heritage.py` 独立挂载 FastAPI + SQLite 两张表：

- `cultural_exchanges`：使馆 ID、双原始藏品 FK（删除时置空）、原始提交者、双作者独立文本、共享题目、私密/公开/结束、使馆快照版本、编辑修订号、各自的同意版本。
- `exchange_passports`：每项文化遗产与真实登录用户 ID 联合主键、当前修订版与用户领取时间。

| 路由 | 用途 |
|---|---|
| `GET /api/heritage/embassies` | 本人参与且双方正式批准的真实 V35 使馆 |
| `GET /api/heritage/sources?embassy_id=` | 双方名下目前仍合法公开的真实原始馆藏 |
| `GET /api/heritage/public` | 当前合法公开、双方最新独立批准的文化礼物联合展 |
| `GET /api/heritage/mine` | 本人参与的联合展与不可用占位 |
| `POST /api/heritage` | 从双方当前公开藏品创建私密文化互赠草稿 |
| `GET /api/heritage/{id}` | 本人私密合作稿或游客可见的共同批准公开稿 |
| `PUT /api/heritage/{id}/note` | 本人只能撰写自己的文化诠释 |
| `PUT /api/heritage/{id}/topic` | 双方成员可修订联合展题，恢复私密等待双方重新批准 |
| `POST /api/heritage/{id}/approve` | 各自独立批准同一版本 |
| `POST /api/heritage/{id}/retract` | 任一方撤回公开与旧授权 |
| `POST /api/heritage/{id}/rebase` | 真实原使馆重新公开后的来源再核验、清空旧双方授权 |
| `POST /api/heritage/{id}/close` | 任一方终止合作，不修改原藏品 |
| `POST /api/heritage/{id}/passport` | 真实登录游客领取一次此版本的虚拟纪念章 |

前端 `static/heritage.js`、`static/heritage.css` 在桌面/手机导航新增「🎁 万界遗产交换站」，支持 `?heritage=<id>` 分享当前真实公开的联合展。
