# V14.0 — 官方馆藏扩展：自然史、古董与科技史

## 新增真实数据源

1. **伦敦自然历史博物馆 Data Portal**：通过公开可读的 CKAN Datastore API 检索馆方「Collection specimens」标本数据集，读取科学名称、馆藏编号、所属科与馆方原档。该数据集在其官方页面标注为 CC0，但这**不等于媒体图片自动获得 CC0 许可**，因此本系统默认不转载标本照片。
2. **大都会艺术博物馆**：通过馆方 **v1.1 paginated search API** 检索珍宝、绘画、古董等。v1/search 已于 2026-10-01 宣告弃用/退役，旧接口调用同步迁移到 v1.1；每次搜索最多读取 8 份详情，图片只有 `isPublicDomain === true` 且 URL 为 `https://images.metmuseum.org/` 时展示。
3. **科学博物馆集团 Science Museum Group**：本期加入官方目录与一件已核验的磁芯存储组件档案链接，尚未完整接入该站 JSON API。该机构图片可能涉及非商业条款，**不批量复制**。
4. **史密森尼 Smithsonian Open Access**：加入官方开放馆藏入口，但其正式 API 要求自行注册 API key，本期不冒充已经连接成功。

## 交互体验

原先的「世界名馆」主页保留 17 件艺术品和现有收藏流程，不另设主导航。追加一个「世界自然史与科技馆藏」专区：6 个专题推荐、馆方切换、关键词查询、馆方原档、权限明确的个人收藏、链接导航。

搜索结果**只来自馆方请求**，没有结果就说明无结果；接口断开时不会编造展品。查询有长短、超时和缓存限制（成功 10 分钟、失败 20 秒），防止对馆方接口造成频繁请求。API 没有凭据要求，但使用者也应遵守馆方数据政策。

用户登录后收藏的是一个「指向馆方官方记录的私人索引」，不是复制作品版权，也不是对年代的真实性认证。服务器从已经校验过的官方搜索响应缓存中取物品、拒绝接受客户端自填来源，默认设置 `visibility=private`，同一用户不会重复导入相同 URL；另一个账号独立收藏。

### 关于时间轴的重要区别

标本的采集/入馆年份 ≠ 化石形成于多少年前；目前只保留馆方采集年份原文，`time_bucket=时间不详`。未来如果某馆明确提供可追溯的地质年龄和证据来源，才会加入「亿年前/百万年前」时间长河。不要为了填满时间轴虚构年代。

## 运行与测试

在完整 V13/V14 工程内安装依赖后：

```bash
PYTHONPATH=. python -m pytest -q tests/test_world_sources_v14.py
node --check static/world-sources.js
node --check static/world-museums.js
```

该版本的 HTTP 适配器和权限逻辑有离线 mock 测试；实际馆方 API 的返回结构与速度仍需在目标网络环境测试。运行网站仍为 `run.bat` → `http://127.0.0.1:8000`。未部署公网。
