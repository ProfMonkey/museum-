# 万物博物馆 V22.0｜人人都是互动展品创造者

本次版本从「网站作者预先做好三个可玩展品」升级为：**任何真实登录的馆长都能使用无代码模板创造、编辑、体验、发布和撤回交互展品。**

## 三种开放创作模板

| 模板 | 作者可以做什么 | 参观者可以做什么 | 技术边界 |
|---|---|---|---|
| 🧩 奇物问答 | 自己编辑问题、四个选项、正确答案与解析 | 答题后从后端获取判定和解析 | 正确答案从公共 GET 响应中剔除；问答不自动认定为可靠史实 |
| 🌱 生命演化 | 设置初始数量、生态容量、增长率、损耗和步数 | 临时调整参数，得到即时折线变化 | 离散逻辑斯蒂模型，不是生物学研究数据或严谨的生态预测 |
| 🎹 16 格旋律机 | 设置 BPM 与 16 个简谱音符或休止符 | 在浏览器播放和自由修改本地旋律 | Web Audio Oscillator 合成波形，不提供上传/托管音乐音频或执行脚本 |

用户完全不需要编写 JavaScript、上传可执行代码、购买 API 或连接外部服务。

## 藏品一体化

- 每创建一件互动作品，后台就**真正创建一条属于该用户的私人藏品**。它会出现在已有的「我的博物馆」里。
- 每个用户最多保存 **15** 件互动作品；默认私人，只有作者本人可预览。
- 作者在造物工坊单独点击「主动公开」后，作品和关联藏品才会一起变成公开状态。
- 作者撤回时，两个记录一起变回私人状态。如果作者在原有藏品编辑页面将关联藏品设为私人，作品的独立公开许可**永久撤回**，即使以后重新公开原藏品，也不会自动公开互动作品。
- 删除互动项目时，只删除它自动创建的那条藏品，绝不会删除用户原有其他藏品。原藏品先删时项目外键级联清理。

## 隐私、真实性及安全

- 私人项目任何未授权用户读取、编辑、操作都得到 404/401；公众只能看到项目和关联藏品都公开的作品。
- 奇物问答的答案**不存入公开藏品简介/故事**，也不随访客 GET 读取；访客必须主动提交答案才会得到判定。
- 生态推演参数有限幅（最多 70 步）；前端用 SVG 绘图。所有数据受 Pydantic 校验，拒绝超出范围、NaN、脚本型额外字段。
- 音乐编辑器音阶为 C4–C5，16 格单声部合成；只在访客主动点击播放时使用浏览器 Web Audio，不自动播放。
- 用户上传内容始终是普通文本及有界参数，无用户自定义 HTML/JavaScript；前端统一转义显示。互动科学与历史说明均展示「用户创作，未经本站独立核验」。
- 没有捏造的玩家、作品、点赞或游玩数据；本版暂不建立排行榜和永久成绩追踪。

## 技术结构

- `creator_studio_api.py`：项目表、模板校验、作者授权、发布与撤回、生态模拟、问答评判。
- `static/studio.js`：可视化问答编辑、生态曲线、16 步旋律与 Web Audio、作者操作 UI。
- `static/studio.css`：适配桌面和移动端的响应式深色博物馆风格。
- `static/play.js`：第三个子页面「✦ 万物造物工坊」。
- `server.py`：新增路由注册，并在原藏品隐私调整中同步撤回相应项目。
- `tests/test_creator_studio_v22.py`：身份、隐私、撤回无法自动复活、问答答案保护、生态参数与计算、音符边界、数据关联与额度的回归测试。

### 主要接口

- `GET /api/play/studio/config`：模板元数据与默认配置。
- `GET /api/play/studio?scope=public|mine`：真实公开作品或我的创作。
- `POST /api/play/studio`：创建私人项目及附属私人藏品。
- `GET /api/play/studio/{id}`：读取项目（公开作者答案不返回）。
- `PUT /api/play/studio/{id}`：作者更新内容。
- `PATCH /api/play/studio/{id}/visibility`：作者主动发布/撤回。
- `DELETE /api/play/studio/{id}`：删除本人作品及自动创建藏品。
- `POST /api/play/studio/{id}/answer`：在服务器校验答案。
- `POST /api/play/studio/{id}/simulate`：独立演算访客自选参数的生态曲线，不改历史。

### 验收

运行 `python -m pytest -q tests`，CI 同时执行所有 `static/*.js` 文件的 `node --check`。本轮自动化测试不代表跨设备实际浏览器端到端、音频策略兼容、公网部署或性能压测已完成。
