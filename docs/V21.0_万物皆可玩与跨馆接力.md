# 万物博物馆 V21.0｜万物皆可玩

本版围绕两个真实可交互的功能：**可操作的简化科学实验台**，以及**由真实馆长共同接力的公开藏品联想链**。

## 互动实验展台

- **轨道探索**：修改轨道半径（0.3–6 AU）与中心质量（0.1–3 太阳质量），即时绘制近似圆轨道和运行速度；服务端计算公转周期与速度。假设是牛顿二体圆轨道，不构成真实轨道预测。
- **齿轮传动**：修改两组齿数与输入转速，视觉演示两齿轮反向转动，并计算理想转速与扭矩倍率。视觉齿形只是原理示意，不保证几何啮合精度。
- **分形宇宙**：移动曼德博集合视点、调节缩放和迭代次数。Canvas 在浏览器本地计算逃逸时间像素；属于有限精度展示，并不证明一个数是否位于无限迭代的集合。
- **私人实验记录**：登录后可以保存最多 30 份由服务器重新计算的实验结果，成为自己的私人藏品。不会自动公开、冒充真实实测结果或带入未经批准的虚构数据。需要主动通过现有藏品编辑流程才能公开。

## 万物接力

1. 从实际存在且仍公开的藏品发起路线，命名自己的接力故事。
2. 其他真实馆长登录后，可以从当前公开展品中选择另一个藏品，解释为什么发生了联想。
3. 每条路线最多 12 站，账号最多发起 10 条，每位馆长每条最多参与 3 站。每一站都有独立的真实投稿者身份记录。
4. 关系类型明确分成「创意联想」与「来源线索」。后者需要 HTTPS 网址，**有 URL 不代表本站验证因果和可信度**。
5. 发起人可以关闭、重启或删除路线，但不能删除其他用户原有藏品。
6. 若起点被设为私密或删除，路线从公共 API 隐藏；若中间节点撤回公开或删除，只展示前面连续有效的节点，不再披露中间或后续节点，也不允许继续追加。私密和原创玄幻展品与真实投稿有不同的标识。

## 页面和 API

- 主导航「⚙ 万物皆可玩」，两个页面「可玩的万物实验」与「万物接力计划」。
- `/api/play/config`、`POST /api/play/preview`、`POST /api/play/records`。
- `/api/play/sources`、`GET/POST /api/play/relays`、`GET/PATCH/DELETE /api/play/relays/{id}`、`POST /api/play/relays/{id}/steps`。
- 公开展品详情加入一键开启万物接力入口。
- 后端 `play_api.py`，前端 `static/play.js`、`static/play.css`，测试 `tests/test_play_v21.py`。

## 验收范围

`python -m pytest -q tests` 运行所有回归；`node --check` 运行第一方 JavaScript 语法检查。真实浏览器端到端、低端安卓设备性能、可访问性和公网压力测试仍需要另行验证。
