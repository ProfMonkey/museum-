# 🌌 万物博物馆 Wonder Atlas V4.0

**万物皆可收藏，每个人都能建造属于自己的世界。**

本项目继承 V3.2 的真实 FastAPI + SQLite 联网多人收藏管理、黑金特色工程、1–6 只网页猴子、三款藏品小游戏等能力，新增 **私人观看足迹 + 回忆剧场**。本项目没有部署公网域名，部署至自己的服务器后多个用户才能跨网络访问。

## 一分钟运行

Windows：解压后双击 `run.bat`。macOS/Linux：执行 `bash run.sh`。或者在项目根目录：

```bash
python -m pip install -r requirements.txt
python -m uvicorn server:app --host 127.0.0.1 --port 8000
```

浏览器访问 `http://127.0.0.1:8000`。**不要直接双击 static/index.html**，因为此项目使用真实后端 API。

## 🌠 V4 新增

- **回忆足迹（默认关闭）**：手动选择开启后，记录自己主动打开过的展品、首次/最近访问时间和总次数。全程与账号绑定，其他用户不可查看。
- **私人回忆片库**：从观看过的展品里选取 1–40 件，排序沿最近浏览顺序，保存命名影片，在同一服务器跨设备使用。
- **沉浸电影模式**：大图、字幕、金色胶片界面、自动翻页、暂停/继续、上一幕/下一幕、全屏、不同速度、键盘左右键与空格操作。
- **可切换的背景音乐**：夜航钢琴 / 星际漫游 / 金色旅途 / 无声，均由浏览器合成演奏；支持选择一个本地音频文件当背景音乐（不上传、不公开）。**不提供受版权保护音乐的外部下载。**
- **偶遇旧日奇物**：随机回访自己过去真正看过的展品，不生成虚假的用户数据。
- **隐私管理**：浏览记录单条移除、全部清除；已保存的影片可以单独删除；公开展品撤回后，别人的影片会自动跳过无权看的画面。

## 原有核心能力

- 多账号注册、登录、公开/私密展品、图片上传、搜索和个人展厅。
- 点赞、评论、关注、通知及展厅布置。
- 黑金封面的 13 项特色工程（底层部分为简化能力，详见 `docs/13项特色工程与开发路线图_v2.0.md`）。
- ProfMonkey 网页小猴：1–6 只、安静/猴山/关闭模式；只在网页里活动。
- V3.2 的奇物碰撞台、猜盲盒、藏品闪记、同类配对等交互玩法。

## GitHub 资产恢复

如果源码来自 GitHub 仓库且使用了独立的 `assets-bundle.zip`，启动脚本会自动从压缩包恢复 `static/assets/` 下的黑金封面和猴子 WebP 素材。官方完整版 ZIP 已附完整素材。恢复逻辑限制写入目录为 `static/assets/`，防止路径穿越。

## 数据与隐私

账号、展品和回忆存储在 `data/wonder.db`，图片存于 `data/media/`；两个位置均已被 `.gitignore` 排除，上传 GitHub 时不要提交真实用户数据库、密码、私人照片、密钥。回忆开启开关按用户存于浏览器的 `localStorage`，默认关闭。不要把正在开发的服务直接开放到公网，公开部署前应额外加强安全、内容审核、存储与备份。
