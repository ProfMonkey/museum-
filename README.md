# 🌌 万物博物馆 Wonder Atlas V6.0

**万物皆可收藏，每个人都能建造属于自己的世界。**

本项目继承 V3.2 的真实 FastAPI + SQLite 联网多人收藏管理、黑金特色工程、1–6 只网页猴子、三款藏品小游戏等能力，新增 **私人观看足迹 + 回忆剧场 + 世界名馆初始典藏 + 万物雷达 + 博物馆导航 + 功能热度统计**。本项目没有部署公网域名，部署至自己的服务器后多个用户才能跨网络访问。

## 一分钟运行

Windows：解压后双击 `run.bat`。macOS/Linux：执行 `bash run.sh`。或者在项目根目录：

```bash
python -m pip install -r requirements.txt
python -m uvicorn server:app --host 127.0.0.1 --port 8000
```

浏览器访问 `http://127.0.0.1:8000`。**不要直接双击 static/index.html**，因为此项目使用真实后端 API。

## 🏛️ V5 新增：世界名馆 · 初始典藏

- 侧边栏和手机导航新增“世界名馆”，与用户上传的社区展品分开。
- 首批 17 件精选作品来自大都会艺术博物馆、芝加哥艺术博物馆和克利夫兰艺术博物馆。
- 通过各馆官方 API 获取作品元数据；只在馆方明确标记 Public Domain / Open Access 或 CC0 时显示原馆图像。
- 支持按博物馆筛选、搜索作品/创作者/文化/年代、查看来源与许可、收入个人博物馆。
- 收入个人馆藏的作品默认私密，不会自动发布到发现广场；保存馆方来源与许可信息，重复收入会被识别。
- 其他名馆官方馆藏入口提供外链，但没有把未接入的馆藏伪装成本站已入库数据。


## ✨ V6 新增：万物雷达与功能热度

- **开放馆藏搜索**：尝试搜索大都会艺术博物馆、芝加哥艺术博物馆和克利夫兰艺术博物馆的官方馆藏。中英文关键词可用；古董、珠宝、项链、戒指、古画、钱币、玉器、瓷器、盔甲、化石等均可尝试。图像只在馆方 API 明确标记开放访问、公有领域或 CC0 时显示。
- **世界博物馆导航**：汇集 50+ 官方入口，按绘画与珠宝、亚洲艺术、自然历史、科技工程、摄影、古籍档案和当代新奇等分组。导航外链与本站实际接入的馆藏 API 分开标示。
- **当代新奇雷达**：Hacker News 科技热榜和 NASA 图像 API，主题覆盖 AI、机器人、芯片、量子、生物技术、互联网奇物、航天与宇宙。外部服务不可用时明确显示提示，不生成虚假的实时内容。
- **一键私藏**：把雷达里的网页或开放馆藏记录保存到个人博物馆，默认私密，保留来源链接。
- **功能热度统计**：统计功能打开、后续操作、活跃用户和“喜欢 / 一般 / 需改进”投票。用户可以更新自己的票。
- **数据最小化**：只记录功能名、动作类型、账号 ID 和时间戳；不记录搜索词、展品 ID、私人内容、完整访问网址或 IP；页面只展示聚合统计。
- **更丰富的收藏分类**：古董珠宝、古币、绘画书画、古籍、历史文物、科技发明、AI 与机器人、航天、矿物宝石、自然化石、时尚、摄影、游戏、互联网奇物、流行文化等。

## 重要的外部数据说明

实时馆藏搜索与科技雷达依赖外部 API 和当前网络；无法连接时，博物馆导航入口仍可用。馆方外链不代表合作关系。任何作品公开转载或商业使用前，都应查看原始记录与最新许可。

## 🌠 V4 新增

- **回忆足迹（默认关闭）**：手动选择开启后，记录自己主动打开过的展品、首次/最近访问时间和总次数。全程与账号绑定，其他用户不可查看。
- **私人回忆片库**：从观看过的展品里选取 1–40 件，排序沿最近浏览顺序，保存命名影片，在同一服务器跨设备使用。
- **沉浸电影模式**：大图、字幕、金色胶片界面、自动翻页、暂停/继续、上一幕/下一幕、全屏、不同速度、键盘左右键与空格操作。
- **可切换的背景音乐**：夜航钢琴 / 星际漫游 / 金色旅途 / 无声，均由浏览器合成演奏；支持选择一个本地音频文件当背景音乐（不上传、不公开）。**不提供受版权保护音乐的外部下载。**
- **偶遇旧日奇物**：随机回访自己过去真正看过的展品，不生成虚假的用户数据。
- **隐私管理**：浏览记录单条移除、全部清除；已保存的影片可以单独删除；公开展品撤回后，别人的影片会自动跳过无权看的画面。

## GitHub 资产恢复

如果源码来自 GitHub 仓库且使用了独立的 `assets-bundle.zip`，启动脚本会自动从压缩包恢复 `static/assets/` 下的黑金封面和猴子 WebP 素材。官方完整版 ZIP 已附完整素材。恢复逻辑限制写入目录为 `static/assets/`，防止路径穿越。

## 数据与隐私

账号、展品和回忆存储在 `data/wonder.db`，图片存于 `data/media/`；两个位置均已被 `.gitignore` 排除，上传 GitHub 时不要提交真实用户数据库、密码、私人照片、密钥。回忆开启开关按用户存于浏览器的 `localStorage`，默认关闭。不要把正在开发的服务直接开放到公网，公开部署前应额外加强安全、内容审核、存储与备份。
