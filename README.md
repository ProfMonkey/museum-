# 🌌 万物博物馆 Wonder Atlas V16.0

**万物皆可收藏，每个人都能建造属于自己的世界。**

本项目继承 V9.0 的真实 FastAPI + SQLite 联网多人收藏管理、黑金特色工程、世界名馆、回忆剧场、跨界探索和展厅工坊，并新增 **双大系列 + 多维分类 + 细化时代轴 + 领域筛选 + 可迁移的 SQLite 字段升级**。本项目没有部署公网域名，部署至自己的服务器后多个用户才能跨网络访问。

## ✵ V16.0：玄幻异界 · 万物炼成与原创世界档案

**万物博物馆既收藏现实世界，也允许用户创建明确标记为虚构的万物。**

- 新主导航「玄幻异界」：原创异界、万物炼成、公共异界藏馆、奇物星图与三途命运（守护／献祭／封印）。
- **六种原创建世界环境＋六条天道规则＋十八种炼材**：无外部模型、不消耗 Token，确定性生成奇物名称、等级、能力、代价、禁忌及原创小传。
- **虚实之门**：可引用用户有权查看的现实藏品作为创作灵感，公开查看者永远无法借此获知他人未公开的源藏品；虚构关系绝非历史因果。
- **与旧系统共用数据**：玄幻奇物也可通过原来的个人展厅、收藏、评论进行展示，元数据强制为「民间奇趣 / 原创与个人创作 / 世界观设定」，历史年代不混入现实时间长河。
- **默认隐私**：创建的世界和奇物均默认私密，公开世界后仍需单件公开奇物；关闭世界自动隐藏全部奇物。普通展品编辑接口无法规避虚构标签与权限限制。
- **玩法区别**：世界规则约束每件奇物的能力与代价；独立的命运三分岔允许为同一件奇物选择不同的虚构结局，但不伪造真实记录。
- **边界**：用户内容仍需遵守版权和运营内容政策；公开部署前需完善举报、反滥用与内容审核。具体接口与设计参见 `docs/V16.0_玄幻异界与万物炼成.md`。

本机运行检查：`PYTHONPATH=. pytest -q tests/test_fantasy_v16.py`；前端语法：`node --check static/fantasy.js`。完整跨版本测试和真实浏览器验收仍需执行。

## V15.0：跨机构真实馆藏联展

- **两家新接入的独立馆藏搜索源**：美国国会图书馆（历史照片/工业技术/早期通信）与 NASA Image and Video Library（航天器/地球观测/天文仪器）。结合 V14 已接入的大都会艺术博物馆、伦敦自然历史博物馆，共支持跨四机构的主题路线。
- **六条非因果参观路线**：盔甲→机械→航天器、古画→航拍→太空摄影、化石→昆虫→地球观测、电报→计算机→深空通信、晶体→光学→太空望远镜、航海图→天文台→月球地图。每站独立查询真实馆藏；路线是一种策展比较，并不声称真实因果联系。
- **来源与版权优先**：NASA/LoC 记录默认只显示文字与馆方档案链接，避免未经单件许可确认就复制图片；记录的拍摄/编目日期不等于技术发明时间，更不等于化石地质年代。
- **私人收藏**：登录后仅能收藏近期由服务器从固定官方接口查询得到的记录，按账号/来源 URL 去重，默认为私密；不能上传任意 URL 伪装馆方结果。明确年份才能进入适当的宽时间段。
- **机构 API 安全**：官方域名固定、搜索限长、最多每次 6 件、响应限 1.5 MB、失败缓存、请求节流（包括国会图书馆 20 次/分钟的公开限制）。断网只展示官方入口，不填虚构条目。
- **入口**：原「世界名馆」页向下滚动至“跨机构真实馆藏探索路线”，未增加新的主导航。完整说明参见 [`docs/V15.0_跨馆真实馆藏探索路线.md`](docs/V15.0_跨馆真实馆藏探索路线.md)。
- **验证**：`PYTHONPATH=. python -m pytest -q tests`，并手动验证 NASA/LoC 真实接口、手机端、版权和登录保存。离线 Mock 单测通过不代表线上接口可用。

## V12.0：世界时光 · 证据追溯 · 私人世界星图

三个功能合并为侧栏唯一的「⏳ 万物时光」入口，避免重复导航：

1. **世界时间长河**：从“亿年前”到“此刻/实时”，按 11 个粗时间尺度浏览**数据库中实际发布的藏品**。可以按系列与领域过滤，登录后可切换查看自己的私密收藏。每个时段独立取样，避免最近内容淹没古老藏品。
2. **证据关联追溯**：从任意可访问展品出发，通过**共享标签、细分类别、领域、时代和来源网站**为相似展品排名。每一条线索展示匹配原因和权重；旧版馆长人工关联单独呈现，明确为尚未核实的用户陈述，绝不虚构历史因果。
3. **我的世界星图**：登录后只对自己的展品生成领域星图、数量分布与自己手动建立的关联。按领域突出，点击星点直接打开藏品；没有行为推断或默认公开。

权限约束：公共时光长河不包括任何私人藏品；证据推荐与馆长关系过滤掉访客无权查看的展品；私人星图仅限当前账号，服务器对数据量设置上限（150 个展品）。实时数据与历史记录均来自已保存的源，不会虚构内容。
来源限制：同网站与同时代只用于弱检索提示，**不是事实核验**。该版本没有自动抓取全文、事实核验或真实 3D 宇宙地图；图形使用轻量 SVG，手机浏览器亦可交互。

完整设计和测试位于 `docs/V12.0_世界时光与智能关联.md`、`tests/test_cosmos.py`。
本机运行：`python -m pip install -r requirements.txt pytest httpx`，`PYTHONPATH=. pytest -q tests`；

## V10.0：万物分类体系（系列 × 领域 × 时代）

- **两个内容大系列**：**藏品系列**（可描述对象、作品、标本和资料，建议附原始来源）与 **民间奇趣**（热梗、趣闻、互联网奇物、个人发现和原创内容）。系列不是可信度认证；没有来源的条目不会被自动标记为已核验。
- **领域轴**：32 个一级领域，包括历史考古、古董收藏、珠宝矿物、视觉艺术、自然史、地球科学、天文航天、物理数学、生命科学、AI、数码产品、游戏、网络文化、影视动漫、音乐、设计、交通、体育、饮食、旅行、日常奇物、原创和开源研究等。
- **细分类别**：各领域有专门的二级分类，同时保留旧版本类别名，旧藏品可继续编辑。
- **时间轴**：亿年前、百万年前、远古与史前、千年至万年前、近千年、近现代、近30年、最近一年、此刻/实时、跨越多个时期、时间不详。
- **时间依据**：形成/演化、制作/创作、发明/发布、发现/出土、走红/传播、事件发生、长期/跨时期、不详。另有自由文本时间备注，保留原始年代写法。
- **组合筛选**：发现广场可交叉筛选系列、领域、细分类别和时代；每件展品可同时归属于一个系列、一个主领域、一个细分类别和一个时间尺度。
- **数据库升级**：启动时会为旧 SQLite 数据库添加新字段并尽量按旧类别映射领域，不会删除原有藏品。完整备份/恢复保留新分类字段。

时间标签是便于检索的宽范围，不应代替来源中的精确年代。大致边界：亿年前为 1 亿年前及更早；百万年前为约 100 万至 1 亿年前；远古与史前为约 1 万至 100 万年前；千年至万年前为约 1000 至 1 万年前；近千年为约 100 至 1000 年前；近现代为约 30 至 100 年前；近30年不含最近一年。对时间跨度很长或年代不确定的内容，应选“跨越多个时期”或“时间不详”，不要强行猜测。

## ✨ V8.0 新增：我的世界成长史（和回忆剧场合一）

- **入口**：登录后进入原来的「回忆剧场」，顶部切换「♫ 回忆剧场 / ✦ 我的世界成长史」，不增加重复侧边导航。
- **可信年度报告**：从当前账号实际的展品、展厅、已保存路线、回忆影片和主动记录的首次观看足迹，实时计算每年新增数、12 个月的趋势、收藏类别和成长时间线。
- **回忆年度影片**：从当年自己新增及首次观看、且当前仍有权打开的展品中编排最多 40 幕；可选择夜航钢琴、星际漫游、金色旅途、无声，直接预览或调用已有私人片库接口保存。
- **可导出年度报告**：本机下载 JSON 摘要（包括个人数据，不会自动上传或公开），留作个人纪念。
- **功能开发建议**：原「功能热度」增加小样本保护的开发方向提示；达不到至少 5 位周期活跃用户和 5 张偏好票时只显示「样本不足」，绝不宣称某功能最受欢迎。
- **没有伪造足迹**：观看记录只有之前用户主动开启记录才会存在，不能反推未保存的观看，也不把跨年累计次数当作本年观看量；旧时已被删除的内容不会凭空恢复。
- **权限与归属**：年度报告要求登录；他人撤回的私密展品不会出现在影片或时间线里；不新增行为追踪表，不会把私人报告作为公共动态。

手动验证：本地启动后注册账号 → 新增一件展品 → 回忆剧场 → 我的世界成长史 → 查看该年度新增数 → 预览影片 → 保存到私人片库。
